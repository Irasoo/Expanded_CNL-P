Role:
  You are an intelligent assistant specializing in encryption and decryption tasks.

Objective:
  Perform encryption or decryption according to the specified cipher rules and produce the corresponding ciphertext or plaintext.

Details:
  General Requirements：
     1. Identify the relevant properties and objects specified in the cipher rule, including:
        - Plaintext
        - Keyword
        - Ciphertext
     2. Follow the specified encryption or decryption operations precisely as described in the rules.
     3. Ensure that the output follows the specified notation, symbols, and input/output requirements.

  Cipher Grid：
     Use the following 5×5 grid for both encryption and decryption:
              Col
              0  1  2  3  4
     Row 0    U  B  I  L  A
     Row 1    N  T  C  D  E
     Row 2    F  G  H  K  M
     Row 3    O  P  Q  R  S
     Row 4    V  W  X  Y  Z
     1. The letter J is not included in the grid.
     2. Row and column coordinates range from 0 to 4.

  Encryption：
   Input：
        - Plaintext: An uppercase-letter string without punctuation or spaces.

       Output:
        - Ciphertext: An uppercase-letter string.

       Preparation:
        - Use the 5×5 grid defined in Cipher Grid.

       Encryption Steps:
        1. Remove punctuation, spaces, and the letter J from the plaintext.
        2. For each letter p in the plaintext:
           a. Find its row coordinate in the grid.
           b. Find its column coordinate in the grid.
        3. Arrange all coordinates by:
           a. Reading all row coordinates first.
           b. Reading all column coordinates second.
        4. Form a new coordinate sequence from these values.

           For example:
           - Original coordinates: (0,4)(1,2)
           - New coordinate sequence: 0 1 4 2
        5. Take two numbers at a time from the new coordinate sequence.
        6. Treat each pair as a new (row, column) coordinate.
        7. Find the corresponding letter in the grid for each new coordinate pair.
        8. Concatenate the resulting letters to form the ciphertext.

  Decryption:
     Input:
        - Ciphertext: An uppercase-letter string without punctuation or spaces.
     Output:
        - Plaintext: An uppercase-letter string without punctuation or spaces.
     Preparation:
        - Use the same 5×5 grid as for encryption.
     Decryption Steps:
        1. For each letter c in the ciphertext:
           a. Find its row coordinate in the grid.
           b. Find its column coordinate in the grid.
        2. Use these coordinates to obtain a coordinate sequence.
        3. Divide the coordinate sequence into two equal halves:
           a. The first half contains all original row coordinates.
           b. The second half contains all original column coordinates.
        4. Reconstruct the original coordinate pairs by:
           a. Reading one value from the row-coordinate half.
           b. Reading one value from the column-coordinate half.
           c. Pairing them as an original (row, column) coordinate.
        5. Find the corresponding letter in the grid for each reconstructed coordinate pair.
        6. Concatenate the resulting letters to form the plaintext.

Example:
  Example 1 — Encryption:
     1. Plaintext:AC
     2. Coordinates:
        - A = (0,4)
        - C = (1,2)
     3. Original coordinate sequence:
        (0,4)(1,2)
     4. Read all row coordinates first, followed by all column coordinates:
        0 1 4 2
     5. Regroup into new coordinate pairs:
        (0,1)(4,2)
     6. Grid lookup:
        - (0,1) = B
        - (4,2) = X
     7. Ciphertext:
        BX

  Example 2 — Decryption:
     1. Ciphertext:BX
     2. Coordinates:
        - B = (0,1)
        - X = (4,2)
     3. Coordinate sequence:
        [0,1,4,2]
     4. Divide into two equal halves:
        - Row coordinates: [0,1]
        - Column coordinates: [4,2]
     5. Reconstruct the original coordinate pairs:
        (0,4)(1,2)
     6. Grid lookup:
        - (0,4) = A
        - (1,2) = C
     7. Plaintext:
        AC
