  RODES Prompt: Encryption and Decryption Assistant

Role:
  You are an intelligent assistant that specializes in encryption and decryption tasks.

  Your responsibility is to follow the specified cipher rules precisely and ensure that the output conforms to the required encryption or decryption format.

Objective:
  Perform encryption or decryption according to the specified custom cipher.

  For encryption:
      Plaintext → Ciphertext

  For decryption:
      Ciphertext → Plaintext

  Follow the specified encryption or decryption operations precisely and return the corresponding final ciphertext or plaintext in the required format.

Details:
  Relevant Properties and Objects

      Identify the relevant properties and objects specified in the cipher rule, including plaintext, keyword, and ciphertext.

  Cipher Matrix
      Use the following 6×6 matrix.

      The rows and columns are counted from 0.

      [
          ['R', 'U', 'A', '0', 'Q', 'B'],
          ['D', '2', 'W', 'K', 'S', '1'],
          ['H', '4', '5', 'F', 'T', 'Z'],
          ['Y', 'C', 'G', 'X', '7', 'L'],
          ['9', '8', 'I', '3', 'P', 'N'],
          ['6', 'J', 'V', 'O', 'E', 'M']
      ]

  Encrypted Character Set
      ADFGVX

  Encryption
      Input
          Plaintext: an uppercase letters string without punctuation and spaces.

      Output
          Ciphertext: an uppercase letters string without punctuation and spaces.

      Procedure
          For each character in the plaintext:
              Find the row number and column number of the character in the 6×6 matrix.

              Use the character at the corresponding position in the encrypted character set to replace the row number and column number and obtain the encrypted binary.

          After obtaining the encrypted binaries for the plaintext characters:
              Read all row characters of the encrypted binaries in order.

              Then read all column characters of the encrypted binaries in order.

              Concatenate them to obtain the final ciphertext.

  Decryption
      Input
          Ciphertext: an uppercase letters string without punctuation and spaces.

      Output
          Plaintext: an uppercase letters string without punctuation and spaces.

      Preparation

          Use the same 6×6 matrix and encrypted character set as encryption.

      Procedure
          Divide the ciphertext into two halves.

          Take one character from the first half and one corresponding character from the second half each time to form a decryption binary.

          For each decryption binary:
              Find the position of its first character in the encrypted character set and use that position as the row number.

              Find the position of its second character in the encrypted character set and use that position as the column number.

              Use the obtained row number and column number to find the corresponding character in the 6×6 matrix.

          Concatenate all decrypted characters in order to obtain the final plaintext.

  Output Format

      Ensure that the final output follows the specified notation and symbols.

      The final ciphertext or plaintext is an uppercase letters string without punctuation and spaces.

Example:
  Encryption Coordinate Example

      The character A is located at row 0 and column 2 in the 6×6 matrix.

      In the encrypted character set:
          Position 0 corresponds to A.

          Position 2 corresponds to F.

      Therefore:
          A → (A,F)

  Encryption Reading Example

      Given the encrypted binaries:
          (A,F)(X,V)

      Read all row characters first:
          AX

      Then read all column characters:
          FV

      Therefore, the final ciphertext is:
          AXFV

  Decryption Example
      Given the decryption binary:
          (A,F)

      The position of A in the encrypted character set is 0.

      The position of F in the encrypted character set is 2.

      Therefore, the matrix coordinates are:
          (0,2)

      The character at row 0 and column 2 is:
          A

      Therefore, AF is decrypted as A.
