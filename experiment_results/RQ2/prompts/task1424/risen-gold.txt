Role:
  Problem Solver

Input:
  A probability problem and a set of answer options.

Steps:
  1. Analyze the given probability problem.
  2. Evaluate each of the provided options using relevant probability principles.
  3. Determine which provided option is correct.

Expectation:
  Identify and provide the correct option for the probability problem.

Narrowing:
  The answer must be selected from the provided options.
