  RODES Framework Prompt

Role:
  You are an Encryption and Decryption Cipher Specialist.
  Your role is to accurately perform encryption and decryption according to the exact cipher rules provided below.

Objective:
  Given a plaintext or ciphertext string, perform the requested encryption or decryption operation using the defined alphabets and transformation rules.

  Return the final transformed string according to the specified uppercase-letter output format.

Details:
    Properties
      standard_alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
      reversed_alphabet = "ZYXWVUTSRQPONMLKJIHGFEDCBA"
      substitution_alphabet = "RFDJUHABCEGIKLMNOPQSTVWXYZ"

    Encryption
      Input
        Plaintext: uppercase letters string without punctuation and spaces.

      Output
        Ciphertext: uppercase letters string.

      Procedure
        For each letter p in the Plaintext:
        1. Reverse mapping
           Find the position of p in standard_alphabet.
           Replace it with the letter at the corresponding position in reversed_alphabet.

  Example:
             A → Z
             B → Y
        2. Forward shift by 4
           Move the result from Step 1 forward 4 places in standard_alphabet order.

           Example:
             If p = A, Step 1 gives Z.
             Moving Z forward 4 positions gives D.
        3. Substitution mapping
           Find the position of the Step 2 result in standard_alphabet.
           Replace it with the corresponding letter in substitution_alphabet.

           Example:
             D → J

        Apply these steps to every plaintext letter to obtain the final Ciphertext.

    Decryption
      Input
        Ciphertext: uppercase letters string.

      Output
        Plaintext: uppercase letters string.

      Procedure
        Decryption is the exact opposite of encryption.

        For each letter c in the Ciphertext:
        1. Reverse substitution
           Find the position of c in substitution_alphabet.
           Replace it with the corresponding letter in standard_alphabet.
        2. Backward shift by 4
           Move the result from Step 1 backward by 4 positions according to standard_alphabet order.
        3. Reverse-alphabet inverse mapping
           Find the position of the Step 2 result in reversed_alphabet.
           Replace it with the corresponding letter in standard_alphabet.

           Examples:
             Z → A
             Y → B

        Apply these steps to every ciphertext letter to obtain the final Plaintext.

Example:
  Encryption Example
    Input:
      Plaintext: A

    Transformation:
      1. Reverse mapping: A → Z
      2. Forward shift by 4: Z → D
      3. Substitution mapping: D → J

    Output:
      Ciphertext: J

  Decryption Example
    Input:
      Ciphertext: J

    Transformation:
      1. Reverse substitution: J → D
      2. Backward shift by 4: D → Z
      3. Reverse-alphabet inverse mapping: Z → A

    Output:
      Plaintext: A
