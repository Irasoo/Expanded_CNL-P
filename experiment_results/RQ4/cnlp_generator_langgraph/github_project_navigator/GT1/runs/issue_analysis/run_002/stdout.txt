`sharkdp/bat` is a Rust-based command-line utility described as “a cat(1) clone with wings.” Its purpose is to display and concatenate files while providing a more readable terminal presentation than traditional `cat`. Core capabilities include syntax highlighting for many programming and markup languages, Git modification indicators, line numbers and file headers, visualization of non-printable characters, configurable output styles and themes, and automatic paging for output longer than one screen. When output is redirected to another process or file, `bat` normally emits plain content so that it can serve as a practical `cat` replacement.

Typical uses include inspecting one or more source files, displaying piped input, concatenating files, previewing search results with tools such as `fzf`, `find`, or `fd`, monitoring logs with `tail -f`, and colorizing output from commands such as `git show`, `man`, and `--help`.
