`sharkdp/bat` is a Rust command-line file viewer and concatenation utility described as “a cat(1) clone with wings.” It is intended for developers, terminal users, and system administrators who want `cat`-compatible output with richer interactive presentation. Its main capabilities include syntax highlighting for many programming and markup languages, Git modification markers, line numbers and file headers, display of non-printable characters, configurable themes and output styles, and automatic paging for output longer than one screen. It accepts file paths or standard input, can display multiple files, and can integrate with tools such as `fzf`, `find`, `fd`, `ripgrep`-related wrappers, `tail`, `git`, `xclip`, and `man`.

Typical uses include inspecting source code and configuration files, previewing search results, viewing Git revisions, monitoring highlighted logs, colorizing help or manual pages, and concatenating files. When output is redirected to a file or another process, `bat` detects the non-interactive destination and normally emits plain file contents, supporting use as a `cat` replacement. Interactive behavior differs from `cat`, however: `bat` automatically invokes a pager for long output. Users who alias `cat` to `bat` and want conventional non-paging behavior should configure `--paging=never`.

Rust is the repository’s primary language.
