`sharkdp/bat` is a Rust command-line utility described as “a cat(1) clone with wings.” It is intended for developers, system administrators, and other terminal users who want to inspect or concatenate files with a more readable presentation than traditional `cat`. Its main capabilities include syntax highlighting for many programming and markup languages, Git modification markers, optional line numbers and file headers, visualization of non-printable characters, configurable themes and output styles, and automatic paging for output longer than one screen. When output is redirected to another process or file, `bat` normally emits plain file contents, allowing it to serve as a practical `cat` replacement.

Typical uses include viewing one or more source files, reading standard input, previewing search results in tools such as `fzf`, displaying Git revisions or nearby diff content, monitoring logs with `tail -f`, and colorizing manual pages or command help. Users can invoke the `bat` executable with file paths or piped input; on some older Debian and Ubuntu releases it is installed as `batcat` because of a package-name conflict. Configuration is available through command-line options, environment variables, and user or system-wide configuration files.

Rust is the repository’s primary language.
