`bat` is the `sharkdp/bat` project, a Rust-based command-line utility described as “a `cat(1)` clone with wings.” Its purpose is to display file contents in a more informative terminal format while remaining usable as a practical replacement for the traditional POSIX `cat` command.

Core capabilities include:

- Syntax highlighting for many programming and markup languages
- Git integration that displays modifications relative to the Git index
- Line numbers, file headers, grids, change markers, and other output decorations
- Display of non-printable characters
- Automatic paging for interactive terminal output
- Plain, non-paged output when used in pipelines or redirected to files
- Reading files, multiple files, and standard input
- Explicit or automatic syntax selection
- Configurable themes, styles, tabs, pager behavior, and syntax mappings
- Custom syntax and theme support through Sublime Text syntax and theme formats
- Shell completion generation
- Optional sanitization and ANSI/control-sequence handling for untrusted or difficult input
- Integration with tools and workflows such as `fzf`, `find`, `fd`, `ripgrep`, `tail -f`, `git`, `man`, and formatting utilities

Typical use cases include inspecting source code in a terminal, previewing files from search or fuzzy-finder results, viewing Git-aware diffs, colorizing manual pages or command help, monitoring logs, concatenating files in scripts, and using a more readable alternative to `cat` during development.

The intended users are developers, system administrators, terminal-focused users, and anyone who regularly reads source code, configuration files, logs, documentation, or command output from a shell. It is primarily a terminal application rather than a graphical editor or general-purpose file viewer.

The primary implementation language is Rust. The main execution entry point is the installed `bat` command, for example `bat README.md`, `bat src/*.rs`, or a pipeline such as `command --help 2>&1 | bat -plhelp`. On some older Debian and Ubuntu systems, the executable may be installed under the name `batcat` because of a package-name conflict. The README documents installation through platform package managers, Homebrew, MacPorts, Nix, Snap-related caveats, Windows package managers, prebuilt Release binaries, crates.io, and local source builds. Building from source requires Rust 1.79.0 or newer; documented Cargo entry points include `cargo install --locked bat` and `cargo install --path . --locked`. The repository also documents `cargo build --bins` for development builds and `cargo test` for tests.
