`bat` is a Rust-based command-line utility from the `sharkdp/bat` repository. Its purpose is to provide a feature-rich, visually enhanced replacement for the Unix `cat(1)` command while remaining useful as a plain file concatenation tool.

Core capabilities include syntax highlighting for many programming and markup languages, Git integration that marks changes relative to the index, line numbers and other output decorations, display of non-printable characters, automatic paging for interactive terminal output, stdin and multi-file input, configurable themes and styles, file-type and syntax mappings, shell-completion generation, and integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `man`, and clipboard utilities. It can also be used as a library, although the README notes that library users must select either the `regex-onig` or `regex-fancy` feature.

Typical use cases include interactively inspecting source code, previewing search results, viewing Git content and diffs, colorizing manual pages or command help, monitoring logs, displaying files with line numbers and Git markers, and piping formatted output into other terminal tools. The intended users are developers, system administrators, terminal-focused users, and anyone who wants more readable command-line file viewing.

The primary technology is Rust. The main execution entry point is the installed `bat` executable, used with commands such as `bat README.md`; on some older Debian or Ubuntu systems the executable may instead be named `batcat`. The README documents installation through operating-system package managers, Homebrew, MacPorts, Nix, Snap alternatives, WinGet, Chocolatey, Scoop, prebuilt Release binaries, crates.io, or a local source checkout. Building from source requires Rust 1.79.0 or newer, with `cargo install --path . --locked` documented as the local installation command and `cargo install --locked bat` as the crates.io entry point. The development entry points include `cargo build --bins`, `cargo test`, and the same locked Cargo installation command.
