`sharkdp/bat` is a Rust command-line utility described as “a cat(1) clone with wings.” It is intended for developers, system administrators, and terminal users who want to inspect, concatenate, or pipe text files while retaining compatibility with common `cat` workflows.

Its core capabilities include syntax highlighting for many programming and markup languages, Git-aware modification markers, optional line numbers and file decorations, display of non-printable characters, automatic paging for long output, configurable themes and output styles, custom syntax definitions, and automatic plain output when writing to a pipe or file. A library API for embedding its pretty-printing features is also documented.

Rust is the repository’s primary language. The principal execution entry point is the `bat` command, although some older Debian and Ubuntu packages install it as `batcat` because of a package-name conflict.
