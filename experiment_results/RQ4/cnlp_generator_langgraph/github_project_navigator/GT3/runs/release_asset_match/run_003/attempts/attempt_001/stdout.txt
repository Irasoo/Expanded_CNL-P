`sharkdp/bat` is a command-line file viewer and `cat(1)` alternative described as “a cat clone with wings.” Its purpose is to make source code, markup, logs, and other text easier to inspect in a terminal while retaining practical `cat`-style behavior.

Core capabilities include syntax highlighting for many programming and markup languages, Git modification markers, line numbers and file headers, highlighting of non-printable characters, automatic paging, configurable output styles, custom themes and syntax definitions, and automatic plain output when redirected to a file or another process. It accepts files or standard input and integrates with tools such as `fzf`, `find`, `fd`, `ripgrep` through `batgrep`, `tail`, `git`, `xclip`, and `man`. It can also be consumed as a Rust library, subject to the README’s feature-selection requirements.

Typical uses include interactively viewing one or more files, previewing search results, inspecting Git revisions, monitoring highlighted logs, colorizing manual pages or help output, and serving as a mostly drop-in `cat` replacement. It is intended primarily for developers, command-line users, system administrators, and others who regularly inspect text in a terminal.

Rust is the repository’s primary language. The normal execution entry point is the `bat` command, although some older Debian and Ubuntu packages install it as `batcat` because of a package-name conflict. Installation paths documented by the project include system package managers on Linux, macOS, Windows, FreeBSD, and OpenBSD; Homebrew, MacPorts, WinGet, Chocolatey, Scoop, and Nix; prebuilt GitHub Release binaries; and source installation with Cargo. Building from source requires Rust 1.79.0 or newer. Windows installations require the Visual C++ Redistributable, and effective paging may require a separate `less` installation.
