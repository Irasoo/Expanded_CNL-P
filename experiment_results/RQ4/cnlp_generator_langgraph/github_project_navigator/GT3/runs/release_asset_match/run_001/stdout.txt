`sharkdp/bat` is a command-line file viewer described as “a cat(1) clone with wings.” Its purpose is to provide a mostly drop-in replacement for POSIX `cat` while making source code, markup, logs, help output, and other text easier to inspect in a terminal.

Its core capabilities include syntax highlighting for many programming and markup languages, Git modification indicators, optional line numbers and file headers, visualization of non-printable characters, automatic paging for long output, stdin support, file concatenation, configurable output styles, custom themes and syntax definitions, and automatic plain output when redirected to another process or file. It can also be used as a previewer or formatter alongside tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `man`, and clipboard utilities.

Typical uses include interactively viewing one or more files, inspecting source code with Git context, previewing search results, highlighting streamed logs or command help, and replacing `cat` in shell workflows. It is primarily intended for developers, system administrators, terminal users, and others who regularly inspect text files or command output. The implementation’s primary language is Rust, and the README also documents a Rust library API for applications that want to use `bat`’s pretty-printing features.

The main execution entry point is the `bat` command, although some older Debian and Ubuntu packages install it as `batcat` because of a package-name conflict. Installation routes documented by the project include system package managers on Linux and BSD, Homebrew or MacPorts on macOS, and WinGet, Chocolatey, or Scoop on Windows. Maintainer-provided prebuilt binaries and Debian packages are available through GitHub Releases. Source installation is supported with `cargo install --locked bat` or `cargo install --path . --locked`; building from source requires Rust 1.79.0 or newer.
