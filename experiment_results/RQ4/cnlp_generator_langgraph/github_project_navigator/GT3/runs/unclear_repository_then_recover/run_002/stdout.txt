`sharkdp/bat` is a Rust command-line utility described as “a cat(1) clone with wings.” It aims to remain usable as a drop-in replacement for POSIX `cat` while providing richer interactive terminal output.

Its core capabilities include syntax highlighting for many programming and markup languages, Git modification indicators, optional line numbers and file headers, visualization of non-printable characters, configurable themes and output styles, and automatic paging for output longer than one screen. It accepts files or standard input, can concatenate multiple inputs, and switches to plain file contents when output is redirected. It also integrates with tools and workflows involving `fzf`, `find`, `fd`, `ripgrep`, `tail`, Git, `xclip`, and `man`.

Typical users are developers, system administrators, and terminal users who inspect source code, configuration files, logs, command help, or Git-tracked files. Common uses include running `bat README.md`, previewing search results, highlighting piped data, monitoring logs, and replacing `cat`. Users who alias `cat` to `bat` may want `bat --paging=never` to preserve `cat`’s non-paging behavior.

The project’s primary language is Rust. Its normal executable is `bat`, although some older Debian and Ubuntu packages install it as `batcat`. Installation entry points documented by the project include operating-system package managers such as `apt`, Homebrew, WinGet, Chocolatey, Scoop, `dnf`, `pacman`, and others; prebuilt Release binaries; and Cargo via `cargo install --locked bat`. Building from source requires Rust 1.79.0 or later. Windows also requires the Visual C++ Redistributable.
