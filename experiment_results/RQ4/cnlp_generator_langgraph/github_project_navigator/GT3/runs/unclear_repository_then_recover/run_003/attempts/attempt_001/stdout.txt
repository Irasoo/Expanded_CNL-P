`sharkdp/bat` is a Rust command-line utility described as “a cat(1) clone with wings.” It is designed to display and concatenate files like POSIX `cat`, while adding syntax highlighting, Git modification markers, line numbers, file headers, non-printable-character visualization, configurable styling, and automatic paging. It accepts file paths or standard input and falls back to plain output when redirected, making it suitable for interactive file inspection, shell pipelines, source-code previews, log monitoring, colorized help and man pages, and integrations with tools such as `fzf`, `find`, `fd`, `ripgrep`, and Git.

The intended users are developers, system administrators, and other terminal users who want a more readable interactive alternative to `cat` without giving up common concatenation and pipeline workflows. Rust is the repository’s primary language. The main executable is normally `bat`, although some older Debian and Ubuntu packages install it as `batcat`. Installation options documented by the project include native package managers on Linux, macOS, BSD, and Windows; project-provided prebuilt Release binaries; and source installation with Cargo using `cargo install --locked bat` or `cargo install --path . --locked`. Building from source requires Rust 1.79.0 or newer, and Windows requires the Visual C++ Redistributable.

Important limitations and operational details include:

- `bat` pages long interactive output by default, so an alias intended to preserve ordinary `cat` behavior should use `bat --paging=never`.
