`sharkdp/bat` is a command-line file viewer and concatenation tool described as “a cat(1) clone with wings.” It is intended for developers, system administrators, and other terminal users who want `cat`-style file output with richer presentation and integration features.

Its core capabilities include syntax highlighting for many programming and markup languages, Git modification markers, optional line numbers and file headers, visualization of non-printable characters, automatic paging, configurable themes and output styles, custom syntax definitions, and reading either files or standard input. When output is redirected to another process or file, `bat` falls back to plain content, supporting many `cat`-compatible workflows. Typical uses include inspecting source code and configuration files, concatenating files, previewing `fzf`, `find`, or `fd` results, displaying `ripgrep` output through related tools, viewing historical Git content, monitoring logs with `tail -f`, and colorizing manual pages or command help.

The project’s primary language is Rust. The main execution entry point is the `bat` command, although some older Debian and Ubuntu packages install it as `batcat` because of a package-name conflict. It can be installed through package managers including `apt`, Homebrew, WinGet, Chocolatey, Scoop, and various Linux and BSD package systems. Maintainers also publish prebuilt binaries. Source installation is available with `cargo install --locked bat` or `cargo install --path . --locked`; the README requires Rust 1.79.0 or newer for source builds. Windows installations require the Visual C++ Redistributable.

Repository metadata reports the license as Apache-2.0, while the README states that users may choose either the MIT License or Apache License 2.0. The repository is not archived, identifies four maintainers, provides contribution and security documentation, and its supplied metadata records a recent update.
