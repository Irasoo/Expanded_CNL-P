`sharkdp/bat` is a Rust command-line utility described as “a cat(1) clone with wings.” It displays and concatenates files like POSIX `cat`, while adding syntax highlighting, Git modification markers, line numbers, file headers, non-printable-character visualization, configurable themes and output styles, and automatic paging for terminal output. When its output is redirected to a file or another process, it normally emits plain file contents, making it suitable for many existing `cat` workflows.

Typical uses include reading source code and markup in a terminal, previewing files in `fzf`, displaying results from `find` or `fd`, monitoring highlighted logs with `tail -f`, viewing historical files from `git show`, colorizing help and man pages, and acting as a formatted output component in shell pipelines. It is primarily intended for developers, command-line users, system administrators, and others who regularly inspect text files. A documented Rust library API is also available for applications that need `bat`’s pretty-printing features.
