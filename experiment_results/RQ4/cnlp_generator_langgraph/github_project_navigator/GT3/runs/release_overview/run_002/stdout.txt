`sharkdp/bat` is a command-line file viewer described as “a cat(1) clone with wings.” Its purpose is to preserve the familiar file-printing and concatenation workflows of POSIX `cat` while adding terminal-oriented presentation features.

Its core capabilities include syntax highlighting for many programming and markup languages, Git modification indicators, line numbers and file headers, visualization of non-printable characters, automatic paging, configurable output styles, and custom syntax and theme support. It reads named files or standard input, handles multiple files, and emits plain content when output is redirected, supporting many `cat`-compatible pipelines.

Typical uses include inspecting source code and configuration files, previewing `fzf`, `find`, or `fd` results, displaying `ripgrep` output through `batgrep`, monitoring logs with `tail -f`, viewing content from `git show`, colorizing manual pages and command help, and concatenating files. It is primarily intended for developers, terminal users, system administrators, and others who regularly inspect text files or compose command-line pipelines. A library API is also documented for Rust applications that need `bat`’s pretty-printing behavior.

Rust is the repository’s primary language. The main execution entry point is the `bat` command, although some older Debian and Ubuntu packages install it as `batcat` because of a package-name conflict. Installation paths documented by the project include system package managers on Linux and BSD, Homebrew or MacPorts on macOS, WinGet, Chocolatey, or Scoop on Windows, official prebuilt Release binaries, and Cargo. Source installation requires Rust 1.79.0 or newer and uses `cargo install --path . --locked`; installation from crates.io uses `cargo install --locked bat`. Windows installations require the Visual C++ Redistributable.

The project is available under either the MIT License or Apache License 2.0, at the user’s option. GitHub metadata identifies Apache-2.0, while the README explicitly documents the dual-license choice.

The repository is not archived, names four maintainers, documents development and contribution workflows, and provides security-reporting guidance.
