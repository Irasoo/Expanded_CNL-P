Project summary:
bat (sharkdp/bat) is a Rust command-line utility that serves as an enhanced, drop-in-style replacement for the POSIX cat command. Its purpose is to make terminal file viewing more readable and informative while retaining cat-like behavior for piping and concatenation. Core capabilities include syntax highlighting for many programming and markup languages, line numbers and other configurable decorations, Git integration that marks changes relative to the index, automatic paging for large interactive output, display of non-printable characters, stdin support, language and file-pattern selection, customizable themes and styles, and configuration through command-line options, environment variables, or a configuration file. It can also be combined with tools such as fzf, find/fd, ripgrep, tail, git, man, and clipboard utilities, and exposes library/API documentation for applications that want to use its pretty-printing features. Typical use cases include inspecting source code and configuration files, previewing files in fzf, viewing Git changes or historical revisions, colorizing man pages and help output, monitoring logs, and replacing cat in shell workflows. Intended users are developers, system administrators, power users, and terminal users who want a more capable and visually annotated file viewer. The primary technology is Rust, with syntax highlighting based on the syntect ecosystem and Sublime syntax/theme files. The main execution entry point is the installed bat command, commonly invoked as "bat FILE" or with piped input; older Debian/Ubuntu packages may install it as batcat. Installation entry points include official or distribution packages through apt, apk, pacman, dnf, emerge, FreeBSD/OpenBSD package tools, zypper, Homebrew, MacPorts, Nix, WinGet, Chocolatey, and Scoop; prebuilt release binaries are also available. From source, the README documents Rust 1.79.0 or newer and cargo install --path . --locked, while crates.io installation uses cargo install --locked bat. The supplied repository is not archived, and the README identifies maintainers, contribution guidance, and a security policy; the metadata also reports a recent update timestamp, so the available data indicates ongoing maintenance rather than abandonment. The README states that bat is available under either the MIT License or Apache License 2.0 at the user's option, although the supplied repository metadata labels the license Apache-2.0. Important limitations and caveats include incomplete automatic detection for stdin and the need to specify a language in some pipelines, native support being limited to UTF-8 and UTF-16 with other encodings generally requiring conversion, possible garbled output from ANSI escape sequences or control characters, a recommendation for truecolor terminals or compatible 8-bit themes, lack of native support for Cygwin-style Windows paths, extra Windows pager/runtime configuration, and a man-page syntax definition that the README says still needs work.
