Project summary:
bat is a Rust-based command-line utility from sharkdp that serves as an enhanced replacement for the Unix cat(1) command. Its purpose is to make terminal file viewing more readable while retaining cat-like behavior for pipelines and redirected output. Core capabilities include syntax highlighting for many programming and markup languages, automatic or explicit language detection, line numbers, file headers, configurable themes and styles, Git modification markers, display of non-printable characters, paging through less or its built-in pager, stdin and multiple-file support, configurable file-type mappings, shell completion generation, and optional sanitization or stripping of ANSI/control sequences. Typical uses include inspecting source code and configuration files, previewing search results with fzf or fd, viewing git show and git diff output, colorizing man pages or command help, monitoring logs with tail -f, and concatenating files in scripts. It is intended for developers, system administrators, terminal users, and anyone who wants a more informative interactive file viewer or cat-compatible pipeline tool. The primary technology is Rust, with syntax highlighting based on the syntect ecosystem and Sublime Text syntax/theme formats. Users can install it through operating-system package managers, Homebrew, MacPorts, Nix, Snap alternatives that are not officially recommended, prebuilt release binaries, or Cargo with `cargo install --locked bat`; source builds use Rust 1.79.0 or newer and can be run with `cargo build --bins`, tested with `cargo test`, or installed locally with `cargo install --path . --locked`. The executable entry point is the `bat` command, although some older Debian or Ubuntu packages install it as `batcat`. The GitHub license metadata identifies Apache-2.0, while the README states that the project is available under either the MIT License or Apache License 2.0 at the user's option.
