Project Overview
**bat** (`sharkdp/bat`) is a Rust command-line utility that extends the traditional POSIX `cat` command with syntax-highlighted file viewing, Git-aware change markers, line numbers, file headers, configurable visual styles, and automatic paging. It is designed to remain a practical `cat` replacement: when output is redirected or piped, `bat` generally emits plain file contents so it can participate in shell pipelines.

Core capabilities include displaying one or multiple files, reading from standard input, manually selecting or automatically detecting a language, highlighting non-printable characters, showing Git modifications, paging long output, customizing themes and decorations, mapping filename patterns to syntaxes, and generating shell completions. It integrates with common terminal workflows and tools such as `fzf`, `find`/`fd`, `ripgrep`, `tail -f`, `git`, `man`, `xclip`, and code formatters through documented command-line combinations. It can also be built or consumed as a Rust library for its pretty-printing features, although the README notes that library users must enable either the `regex-onig` or `regex-fancy` feature.

Typical users are developers, system administrators, and terminal-focused users who inspect source code, configuration files, logs, diffs, command help, or search results interactively. Common use cases include previewing files in `fzf`, reviewing Git changes, colorizing manual pages and help output, monitoring logs, and replacing `cat` in an interactive shell. The primary technology is Rust, with syntax highlighting based on the `syntect` library and Sublime Text syntax definitions and themes.

The main execution entry point is the installed `bat` executable, for example `bat README.md`, `bat src/*.rs`, or a pipeline such as `command | bat`.
