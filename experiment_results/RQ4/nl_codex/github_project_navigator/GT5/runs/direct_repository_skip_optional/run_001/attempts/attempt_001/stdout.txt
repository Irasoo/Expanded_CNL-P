bat is the sharkdp/bat project, a Rust-based command-line utility described as a “cat(1) clone with wings.” It is intended to be a drop-in replacement for POSIX `cat` that makes terminal file viewing more readable while retaining standard concatenation and piping behavior.

Core capabilities include syntax highlighting for many programming and markup languages, configurable themes and file-type associations, line numbers and other output decorations, Git integration that marks working-tree changes relative to the index, automatic paging, display of non-printable characters, stdin support, configurable tab expansion, and plain-output modes for scripting or copying content.
