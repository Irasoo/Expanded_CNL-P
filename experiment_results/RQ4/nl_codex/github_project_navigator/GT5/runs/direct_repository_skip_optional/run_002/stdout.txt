Project Overview
## sharkdp/bat

**bat** is a Rust-based command-line utility that acts as an enhanced `cat(1)` replacement. It prints files and standard input with syntax highlighting, optional line numbers and visual decorations, Git change markers, non-printable-character highlighting, and automatic paging for output larger than one terminal screen. When output is redirected or piped, it can fall back to plain file contents for compatibility with typical Unix command pipelines.

Core capabilities include highlighting many programming and markup languages, displaying multiple files or concatenating file contents, reading from stdin, selecting languages explicitly, showing Git modifications, configuring themes and output styles, using custom syntax definitions, and integrating with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `man`, and `xclip`. It also provides shell completion generation, configuration files, a built-in pager option, and a library API for applications that need its pretty-printing features.

Typical users are software developers, system administrators, terminal-focused users, and anyone who regularly inspects source code, configuration files, logs, command output, or Git-managed files. Common use cases include interactively viewing source files, previewing search results in `fzf`, colorizing manual pages or `--help` output, monitoring logs, reviewing diffs, and using `bat` as a visually richer replacement for `cat` while preserving pipeline behavior.

The main execution entry point is the `bat` executable, for example `bat README.md`, `bat src/*.rs`, or `command | bat`. Installation is available through system package managers including `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `pkg_add`, `zypper`, Homebrew, MacPorts, Nix, WinGet, Chocolatey, and Scoop, as well as prebuilt binaries from GitHub Releases. From source, the README requires Rust 1.79.0 or newer and supports `cargo install --locked bat` or `cargo install --path . --locked`. The project can also be built and tested with `cargo build --bins` and `cargo test`.

The primary implementation language is **Rust**. Syntax highlighting is based on the `syntect` library and Sublime Text syntax and theme formats. The repository is not archived, and the supplied metadata reports an update on 2026-09-12, indicating that it is maintained rather than discontinued.
