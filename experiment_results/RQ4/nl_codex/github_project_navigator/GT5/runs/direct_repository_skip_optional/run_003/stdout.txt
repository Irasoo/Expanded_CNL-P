Project Overview
**bat** (`sharkdp/bat`) is an actively maintained, non-archived Rust command-line utility that serves as an enhanced `cat(1)` replacement. It prints one or more files, or stdin, with syntax highlighting, optional line numbers and other terminal decorations, Git change markers, non-printable-character visualization, configurable themes and styles, and automatic paging for output that exceeds one screen.

It is primarily intended for developers, system administrators, terminal users, and anyone who regularly inspects source code, configuration files, logs, documentation, or command output. Typical uses include viewing files interactively, previewing search results from `fzf`, `find`, or `fd`, displaying colored `git diff` output, monitoring logs with `tail -f`, colorizing manual pages or `--help` output, and concatenating files in pipelines. When output is redirected or piped, `bat` automatically falls back toward plain `cat`-style output; options such as `--plain`, `--paging=never`, and `--color=always` allow this behavior to be controlled explicitly.

The core implementation is written in Rust. Syntax highlighting is provided through the `syntect` ecosystem and Sublime Text syntax definitions and themes. The main execution entry point is the `bat` executable, used directly from a shell, for example `bat README.md` or `curl ... | bat`. It can be installed through common system package managers including `apt`, `apk`, `pacman`, `dnf`, Homebrew, MacPorts, Nix, WinGet, Chocolatey, Scoop, and BSD package systems; prebuilt binaries are available from GitHub Releases. Building from source requires Rust 1.79.0 or newer and can be done with `cargo install --locked bat` or `cargo install --path . --locked`. The repository also documents `cargo build --bins` and `cargo test` for development. A library API is available through `docs.rs`, although library consumers must enable either the `regex-onig` or `regex-fancy` feature.
