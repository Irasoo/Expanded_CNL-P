Project Overview
## sharkdp/bat

**bat** is a Rust command-line utility designed as a feature-rich replacement for the POSIX `cat(1)` command. Its purpose is to make terminal file viewing more readable while remaining usable in pipelines and scripts.

### Core capabilities

- Syntax highlighting for many programming and markup languages, using `syntect` and Sublime Text syntax definitions.
- Git integration that displays modifications relative to the Git index.
- Line numbers, file headers, grids, change markers, file sizes, and other configurable output decorations.
- Automatic paging for large interactive output, using `less`, another configured pager, or its built-in pager.
- Plain `cat`-style behavior when output is redirected or piped to another command.
- Display and highlighting of non-printable characters.
- Automatic or explicitly selected language detection for files and standard input.
- Customizable themes, styles, syntax mappings, tabs, paging, color handling, and configuration files.
- Shell completion generation and integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and code formatters.

### Typical users and use cases

The intended users are developers, system administrators, and terminal-focused users who regularly inspect source code, configuration files, logs, command output, or Git changes. Common uses include viewing one or more files, previewing search results with `fzf` or `fd`, colorizing piped input and manual pages, inspecting historical files with `git show`, monitoring logs with `tail -f`, and using `bat` as a more readable interactive `cat` replacement.

### Technology and entry points

The primary implementation language is **Rust**. The main execution entry point is the installed `bat` command, for example `bat README.md`, `bat --help`, or `bat --version`. It can be installed through operating-system package managers, Homebrew, MacPorts, Nix, Snap alternatives, Windows package managers, or prebuilt release binaries. From source, the README documents Rust 1.79.0 or newer and these Cargo entry points:

A library API is available through the `bat` crate, although library consumers must enable either the `regex-onig` or `regex-fancy` feature.

### Important README limitations and caveats

- Interactive output is paged by default; use `--paging=never` when continuous or pipeline-friendly output is required. Non-interactive output automatically falls back to plain file contents.
- Automatic syntax detection for standard input is limited; it generally needs a recognizable first line, such as a shebang. Use `-l`/`--language` when detection is unreliable.
- UTF-8 and UTF-16 are supported natively. Other encodings may need conversion to UTF-8 with a tool such as `iconv`.
- Syntax highlighting themes work best with terminals that support 24-bit true color. Restricted-color terminals may require the documented 8-bit themes.
- Input containing ANSI escape sequences or control characters can produce garbled highlighting or wrapping. The README documents `--strip-ansi` and `--sanitize` options for relevant cases.
- Windows users may need the Visual C++ Redistributable and a better pager such as `less`. Native Windows `bat` does not directly understand Cygwin-style `/cygdrive/*` paths without a wrapper.
- The README says custom themes must currently use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported.
