Project Overview
**bat** is a Rust command-line utility described as “a cat(1) clone with wings.” It is designed as a user-friendly replacement for POSIX `cat` that preserves normal file and pipeline workflows while adding syntax highlighting, Git-aware change markers, line numbers, file headers, paging, and configurable terminal presentation.

**Core capabilities**
- Syntax highlighting for many programming, markup, configuration, and other text languages, using the `syntect` library and Sublime Text syntax definitions.
- Git integration that displays modifications relative to the Git index.
- Automatic paging for interactive output, with support for `less`, a built-in pager, or another configured pager.
- Plain, pipeline-friendly behavior when output is redirected or sent to a non-interactive process.
- Reading one or multiple files, concatenating files, and reading from standard input.
- Automatic or explicitly selected syntax detection, including support for custom language mappings.
- Display of line numbers, non-printable characters, file metadata, grids, and other output decorations.
- Configurable themes, styles, tab expansion, color behavior, paging, sanitization, and configuration files.
- Shell completion generation and cache management for custom syntaxes and themes.

**Typical use cases**
Developers and terminal users commonly use `bat` to inspect source files, preview search results from tools such as `fzf`, `find`, `fd`, and `ripgrep`, view Git output, colorize manual pages or command help, follow logs with `tail -f`, and replace `cat` in interactive shell workflows. It can also be used in scripts and pipelines, where it falls back toward plain `cat`-style output when appropriate.

The intended users are software developers, system administrators, terminal-focused users, and anyone who regularly reads text files from a command line. It is primarily an interactive terminal viewer, although its non-interactive behavior supports use in pipelines and file redirection.
