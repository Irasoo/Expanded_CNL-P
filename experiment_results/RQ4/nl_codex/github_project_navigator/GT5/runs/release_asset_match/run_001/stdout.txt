Project Overview
`sharkdp/bat` is a Rust-based command-line utility that serves as an enhanced `cat(1)` replacement for viewing and concatenating files in a terminal. Its main purpose is to make source code and other text easier to inspect while retaining compatibility with ordinary shell pipelines.

Core capabilities include syntax highlighting for many programming and markup languages, line numbers, file headers, configurable output styles and themes, Git modification markers, automatic paging, stdin and multi-file input, non-printable-character highlighting, syntax and theme customization, shell completion generation, and optional sanitization or stripping of terminal control sequences. When output is redirected or piped, `bat` detects the non-interactive context and can emit plain file contents, which supports use in scripts and Unix pipelines.

Typical users are developers, system administrators, and terminal-focused users who inspect source files, logs, configuration, command output, Git revisions, or search results.
