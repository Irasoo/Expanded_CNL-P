Project Overview
## sharkdp/bat

**bat** is a Rust-based command-line utility that acts as an enhanced `cat(1)` replacement. Its purpose is to display files and streamed text in a more readable, terminal-oriented format while retaining `cat`-style behavior for non-interactive output.

### Core capabilities

- Syntax highlighting for many programming and markup languages.
- Git integration that marks changes relative to the repository index.
- Optional line numbers, file headers, grids, separators, and other output decorations.
- Automatic paging for output that is larger than the terminal window, using `less` or another configured pager.
- Reading from files, multiple files, standard input, or a combination of files and standard input.
- Display of non-printable characters with `-A`/`--show-all`.
- Automatic or explicitly selected language detection.
- Configurable themes, styles, color behavior, wrapping, tab expansion, and paging.
- Support for custom Sublime Text syntax definitions and `.tmTheme` themes.
- Shell-completion generation and a configuration file for persistent options.
- Use as a component in workflows involving tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and clipboard utilities.
- A library interface for applications that want to use its pretty-printing functionality, documented through docs.rs.

### Typical use cases

Users commonly run `bat` to:

- Inspect source code, configuration files, documentation, and logs with highlighting and line numbers.
- Preview files selected by `fzf`, `fd`, or `find`.
- Review Git changes or view historical files with readable syntax highlighting.
- Colorize piped output such as help messages, formatted data, or command results.
- Browse manual pages through a colorizing pager.
- Replace or supplement `cat` in interactive shell workflows while disabling decorations and paging when plain concatenation is required.

For example, a basic invocation is `bat README.md`; `bat` can also process standard input, such as `curl -s URL | bat`, or be used in a pipeline with options such as `--paging=never` and `--language`.
