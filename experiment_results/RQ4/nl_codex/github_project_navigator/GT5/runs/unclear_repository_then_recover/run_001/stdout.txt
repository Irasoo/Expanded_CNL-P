**bat** (`sharkdp/bat`) is a maintained Rust command-line utility that acts as an enhanced `cat(1)` replacement. It displays files and streams with syntax highlighting, line numbers, file headers, Git modification markers, configurable themes and styles, and automatic paging for output that exceeds one terminal screen. It falls back to plain file contents when output is redirected, preserving use as a pipeline-friendly `cat` substitute.

Core capabilities include displaying one or multiple files, reading from standard input, selecting or auto-detecting languages, highlighting non-printable characters, showing Git changes, configuring themes and decorations, mapping file patterns to syntaxes, generating shell completions, and customizing behavior through environment variables or a configuration file. Typical users are developers, system administrators, and terminal-focused users who inspect source code, configuration files, logs, command output, or Git revisions from a shell.
