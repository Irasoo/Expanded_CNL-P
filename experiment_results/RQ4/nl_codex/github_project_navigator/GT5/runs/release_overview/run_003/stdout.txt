Project Overview
**bat** is an open-source Rust command-line utility that serves as an enhanced `cat(1)` replacement. Its purpose is to display files and standard input in a terminal while adding syntax highlighting, line numbers, file headers, Git change markers, configurable themes and styles, and automatic paging.

**Core capabilities:**
- Syntax highlighting for many programming, markup, configuration, and shell-related languages.
- Git integration that marks changes relative to the index.
- Interactive paging through `less` or bat's built-in pager when output exceeds the terminal height.
- Plain, pipeline-friendly output when writing to a file or another command.
- Display of non-printable characters, configurable line ranges, tab expansion, wrapping, color behavior, and decorations.
- Input from one or multiple files, standard input, and mixed file/stdin sequences.
- Custom syntax definitions, themes, file-type mappings, configuration files, shell completions, and library/API use.
- Integration patterns for tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and code formatters.

Typical use cases include inspecting source code from a terminal, previewing search or fuzzy-finder results, reviewing Git changes, colorizing manual pages and command help, monitoring logs, and using a visually richer replacement for `cat` in shell workflows. It is primarily intended for software developers, system administrators, terminal-focused users, and anyone who regularly reads text files from the command line.

The primary technology is Rust. The main execution entry point is the installed `bat` executable, used with commands such as `bat README.md`, `bat src/*.rs`, or `curl ... | bat`. It can be installed through operating-system package managers including `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `pkg_add`, `nix`, `zypper`, Homebrew, MacPorts, WinGet, Chocolatey, and Scoop; through prebuilt binaries on the GitHub Releases page; or from source with Rust 1.79.0 or newer using `cargo install --locked bat` or `cargo install --path . --locked`.
