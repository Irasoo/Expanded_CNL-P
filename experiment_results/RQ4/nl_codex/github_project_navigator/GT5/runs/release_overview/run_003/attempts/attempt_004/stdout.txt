Project Overview
bat (sharkdp/bat) is a Rust-based command-line file viewer and `cat(1)` alternative. It preserves plain concatenation behavior when output is redirected, while making interactive terminal viewing easier through syntax highlighting, line numbers, file headers, Git change markers, non-printable-character display, text wrapping, and automatic paging. It can read one or more files or standard input, and its output appearance, themes, syntax mappings, pager, and other defaults can be configured through command-line options, environment variables, or a configuration file.

Typical uses include inspecting source and markup files, replacing or aliasing `cat`, previewing files in `fzf`, displaying `find` or `fd` results, monitoring logs with `tail -f`, formatting piped command help, and viewing content from commands such as `git show`. It is intended primarily for developers, system administrators, and other terminal users. Its highlighting is powered by `syntect`, supports many programming and markup languages, and can be extended with Sublime Text `.sublime-syntax` definitions and `.tmTheme` themes. The crate also exposes pretty-printing functionality for Rust applications, subject to the documented regex feature requirement.

The main execution entry point is the `bat` executable, although some older Debian and Ubuntu packages install it as `batcat`. Examples include `bat README.md`, `bat src/*.rs`, and piped input such as `command | bat -l json`. Installation is available through common Linux, BSD, macOS, and Windows package managers, downloadable release binaries, or Rust's package manager with `cargo install --locked bat`.
