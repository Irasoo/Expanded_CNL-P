Project Overview
bat (sharkdp/bat) is a Rust command-line utility described as “a cat(1) clone with wings.” It displays files or standard input in the terminal while adding syntax highlighting, Git change markers, line numbers, file headers, visible non-printable characters, configurable output styles, and automatic paging. When its output is redirected or piped, it normally falls back to plain file contents, which allows it to cover many traditional `cat` workflows.

Typical uses include inspecting source and markup files, concatenating files, previewing search results in `fzf`, formatting `ripgrep` or `find` output, viewing historical files from Git, following highlighted logs with `tail -f`, and acting as a colorizing pager for manual pages or command help. It is primarily intended for developers, system administrators, and other terminal users. Its highlighting is based on `syntect`; users can add Sublime Text `.sublime-syntax` definitions and `.tmTheme` themes, map filename patterns to languages, and configure behavior through command-line options, environment variables, or a configuration file. Packages are documented for major Linux and BSD distributions, Homebrew and MacPorts, and Windows package managers including WinGet, Chocolatey, and Scoop.
