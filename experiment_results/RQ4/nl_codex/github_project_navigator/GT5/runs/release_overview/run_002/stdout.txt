Project Overview
**bat** (`sharkdp/bat`) is a Rust command-line utility that serves as an enhanced `cat(1)` replacement. It displays files with syntax highlighting, line numbers, headers, paging, Git modification markers, configurable themes and styles, and optional highlighting of non-printable characters. It also preserves `cat`-like behavior when output is redirected or piped.

**Core capabilities:**
- Syntax highlighting for many programming, markup, configuration, and other text languages through `syntect` and Sublime Text syntax definitions.
- Git integration that shows working-tree modifications beside file contents.
- Automatic paging through `less` or another configured pager, with a built-in pager option.
- File concatenation, stdin support, line-range selection, explicit language selection, color and decoration controls, tab expansion, and configurable output styles.
- Custom syntax definitions, themes, file-type mappings, configuration files, and shell completion generation.
- Integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and formatters.

Typical users are developers, system administrators, and terminal users who inspect source code, logs, configuration files, diffs, command output, or documentation from a shell. Common use cases include previewing files in `fzf`, viewing Git changes or historical files, colorizing manual pages and help output, monitoring logs, and using `bat` as a more readable interactive replacement for `cat`.

The primary technology is **Rust**. The normal execution entry point is the installed `bat` executable, for example `bat README.md`, `bat src/*.rs`, or a pipeline such as `command | bat`. On some older Debian and Ubuntu releases the executable is named `batcat`. Installation is available through operating-system package managers including `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `pkg_add`, Nix, Homebrew, MacPorts, WinGet, Chocolatey, and Scoop; prebuilt binaries are provided through GitHub releases. From source, the README requires Rust 1.79.0 or newer and supports `cargo install --locked bat` or `cargo install --path . --locked`.
