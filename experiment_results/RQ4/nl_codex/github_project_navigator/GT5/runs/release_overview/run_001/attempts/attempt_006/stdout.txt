Project Overview
**bat** is a maintained, cross-platform Rust command-line utility from `sharkdp/bat`. It is designed as a more capable `cat(1)` replacement: it displays files with syntax highlighting, optional line numbers and other visual decorations, Git modification markers, and automatic paging for output that exceeds the terminal height.

**Core capabilities** include highlighting many programming and markup languages, reading files or standard input, concatenating multiple files, showing non-printable characters, detecting whether output is interactive or piped, displaying changes relative to the Git index, selecting themes and output styles, configuring pagers, generating shell completions, and extending syntax definitions and themes. It can also be integrated with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and code formatters.
