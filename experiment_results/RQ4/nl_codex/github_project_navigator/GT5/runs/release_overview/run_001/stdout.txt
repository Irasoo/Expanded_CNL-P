Project Overview
**bat** is an actively maintained, cross-platform Rust command-line utility from `sharkdp/bat`. It is designed as an enhanced `cat(1)` replacement: it prints files and standard input while adding syntax highlighting, line numbers, file headers, configurable visual decorations, automatic paging, and Git modification markers. Its stated goals are to provide advanced, attractive highlighting, Git integration, a user-friendly CLI, and compatibility with normal `cat` workflows.

Core capabilities include displaying one or many files, concatenating files and stdin, automatically or explicitly selecting a language, highlighting non-printable characters, showing Git changes, selecting themes and output styles, configuring tabs and pagers, mapping file patterns to syntaxes, and generating shell completions. It integrates naturally with tools such as `fzf`, `find`/`fd`, `ripgrep`, `tail -f`, `git`, `man`, `xclip`, and code formatters. It can also be used as a library, although library consumers must enable either the `regex-onig` or `regex-fancy` feature.

Typical users are developers, system administrators, and terminal-oriented users who inspect source code, configuration files, logs, command output, search results, or manual pages. Common entry points include `bat README.md`, piping data into `bat`, or using it as an `fzf` previewer. It can be installed through operating-system package managers on major Linux and BSD distributions, Homebrew or MacPorts on macOS, WinGet, Chocolatey, or Scoop on Windows, Nix, release binaries, or Rust tooling. From source, the README requires Rust 1.79.0 or newer and documents `cargo install --path . --locked`; from crates.io, it documents `cargo install --locked bat`. The primary executable is `bat`.

The primary technology is Rust. The project uses the `syntect` library for Sublime Text syntax definitions and themes. The repository is not archived and the supplied GitHub metadata reports an update on `2026-09-12`, indicating ongoing maintenance. The supplied repository license field is `Apache-2.0`; however, the README states that the software is available under either the MIT License or Apache License 2.0, at the user's option, with separate `LICENSE-MIT` and `LICENSE-APACHE` files.

Important README limitations and operational details: output is automatically paged in interactive terminals, but when output is redirected or piped, `bat` falls back to plain file contents unless colorization or decorations are explicitly forced. Automatic stdin language detection generally depends on information in the first line, such as a shebang, so the language may need to be specified with `-l`. UTF-8 and UTF-16 are supported natively; other encodings may need conversion to UTF-8. ANSI escape sequences and control characters can cause garbled highlighting or wrapping, although stripping and sanitization options are available. Good color output depends on terminal support, and the README recommends truecolor terminals or compatible 8-bit themes. Windows requires the Visual C++ Redistributable, and Cygwin absolute paths need a wrapper because native Windows `bat` does not understand Cygwin paths. Custom themes must use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported. Installing from source or crates.io does not automatically install the man page or shell completion files. The README also says that no recommended snap package is officially supported.
