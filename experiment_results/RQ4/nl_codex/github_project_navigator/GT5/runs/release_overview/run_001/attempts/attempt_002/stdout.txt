Project Overview
## bat — a cat(1) clone with wings

**bat** is a command-line replacement for the Unix `cat` utility. It displays files and standard input with syntax highlighting, configurable visual decorations, line numbers, paging, and Git change markers. Its goal is to retain `cat`-style composability while making source code and other text more readable in a terminal.

### Core capabilities

- Syntax highlighting for many programming and markup languages.
- Git integration that marks changes relative to the repository index.
- Automatic paging for output that exceeds one screen, with support for `less` and a built-in pager.
- Display of line numbers, file names, file sizes, grids, separators, and non-printable characters.
- Automatic syntax detection where possible, with explicit language selection when needed.
- Reading files, multiple files, standard input, or mixed file/stdin input.
- Configurable themes, styles, colors, tab expansion, wrapping, decorations, and pager behavior.
- Custom syntax definitions and themes through its configuration directory and cache commands.
- Shell-completion generation and configuration through command-line options, environment variables, or a configuration file.
- Integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `man`, and formatters.
- A library/API is also documented, although the project is primarily presented as a command-line application.

### Typical use cases

Users commonly use `bat` to inspect source files, configuration files, logs, documentation, and command output. Examples include previewing files in `fzf`, viewing Git revisions or diffs, following logs with `tail -f`, colorizing manual pages and help output, and replacing `cat` in interactive shell workflows. When output is redirected or piped, `bat` generally falls back toward plain, composable file output rather than treating the result as an interactive display.

### Intended users

The project is intended for developers, system administrators, terminal-oriented users, and anyone who regularly reads text or source code from a shell. It is particularly useful for people who want `cat`-like behavior with syntax-aware presentation, paging, and Git context. It supports Linux, macOS, Windows, BSD variants, and several package-management ecosystems, subject to the platform-specific requirements described in the README.
