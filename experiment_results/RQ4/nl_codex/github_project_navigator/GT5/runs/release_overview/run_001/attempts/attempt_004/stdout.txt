Project Overview
## bat — a cat(1) clone with wings

**bat** is a cross-platform command-line utility from [sharkdp/bat](https://github.com/sharkdp/bat) that provides a more informative way to display files in a terminal. It aims to remain a drop-in replacement for the POSIX `cat` command while adding syntax highlighting, Git integration, line numbers, paging, and configurable visual formatting.

### Purpose and core capabilities

bat can:

- Display one or more files with syntax highlighting for many programming and markup languages.
- Read file contents from standard input and, when possible, determine the syntax automatically.
- Show line numbers, file headers, grids, file sizes, and Git modification markers.
- Communicate with Git to show changes relative to the index.
- Highlight non-printable characters with `-A`/`--show-all`.
- Automatically page long interactive output, using `less` or another configured pager.
- Behave like ordinary `cat` when output is redirected or piped, unless options explicitly request decorations or color.
- Customize themes, styles, tab handling, syntax associations, paging, and configuration files.
- Add custom Sublime Text syntax definitions and `.tmTheme` themes through a generated cache.
- Generate shell completions and operate as a library, according to the README’s API documentation.

It can be used alongside tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail -f`, `git`, `man`, `xclip`, and formatting tools such as `prettier`, `shfmt`, and `rustfmt`.

### Typical use cases

Typical examples include viewing source code or documentation with highlighting, previewing search results in `fzf`, inspecting Git-modified files, viewing `git diff` output, colorizing manual pages or command help, monitoring logs with `tail -f`, and concatenating files in scripts or pipelines. For example:

```bash
bat README.md
bat src/*.rs
bat -A /etc/hosts
curl -s https://example.org/file.rs | bat -l rs
```

### Intended users

The project is intended primarily for command-line users, software developers, system administrators, and anyone who regularly reads source code, configuration files, logs, documentation, or command output in a terminal. It is also suitable for users who want a visually enhanced `cat` replacement or a terminal previewer for other command-line tools.

### Technology

Git is used for repository-change information, and external or built-in pagers can be used for long output. The repository also provides Cargo-based development and installation workflows.

### Important README limitations and caveats

- Automatic syntax detection for standard input is limited: highlighting generally works only when the language can be inferred from the first line, commonly through a shebang. Use `-l`/`--language` when necessary.
- UTF-8 and UTF-16 are supported natively, but other encodings may need conversion to UTF-8 first, for example with `iconv`.
- Inputs containing ANSI escape sequences or other control characters can produce garbled highlighting or wrapping. The README recommends `--strip-ansi`, `--sanitize`, or disabling color and wrapping for affected or untrusted input.
- Terminal appearance depends on color support. The README recommends a 24-bit truecolor terminal for most themes or one of the restricted 8-bit themes for terminals with limited color capabilities.
- Paging and decorations vary between interactive and redirected output. Piped output normally falls back to plain file contents, so `--color=always`, `--decorations=always`, or related options may be needed for preview integrations.
- Older Debian and Ubuntu packages may install the executable as `batcat` rather than `bat` because of a package-name conflict.
- Windows users need the Visual C++ Redistributable. The README also notes that Cygwin Unix-style paths are not natively supported without a wrapper or path conversion, and that a suitable pager may require separate installation or configuration.
- The README says the bundled Manpage syntax still needs work.
- Custom themes must currently use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported.
- Installing from source or crates.io with Cargo does not automatically install additional files such as the man page or shell-completion files.
