Project Overview
## bat (sharkdp/bat)

**bat** is a Rust-based command-line utility that acts as an enhanced replacement for the Unix `cat(1)` command. Its primary purpose is to display and concatenate files in a terminal while making source code and other text easier to read through syntax highlighting, line numbers, file headers, Git change markers, themes, and optional paging.

### Core capabilities and typical use cases
- Syntax highlighting for many programming, markup, configuration, and other text formats.
- Git integration that marks lines changed relative to the Git index.
- Automatic paging for output that is longer than the terminal screen, with support for `less` and a built-in pager.
- Plain, pipe-friendly behavior: when output is redirected or piped, `bat` falls back to file contents without terminal decorations.
- Display of line numbers, non-printable characters, file metadata, grids, and other configurable decorations.
- Reading files, multiple files, or standard input; syntax can be selected automatically or explicitly with `-l`/`--language`.
- Configurable themes, output styles, pager behavior, tab expansion, syntax associations, and user or system-wide configuration files.
- Extensibility through additional Sublime Text syntax definitions and `.tmTheme` themes.
- Integration with terminal workflows and tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail -f`, `git`, `man`, and clipboard utilities. It can also be used to colorize command help output.

Typical uses include inspecting source code, previewing files in fuzzy finders, viewing Git output, monitoring logs, reading manual pages, highlighting piped data, and using `bat` as a more readable interactive `cat` replacement.

### Intended users
The project is aimed primarily at developers, system administrators, command-line users, and anyone who regularly inspects source code, configuration files, logs, or command output in a terminal. It is also usable as a component in shell scripts and other command-line pipelines, where its non-interactive behavior is intended to remain compatible with `cat`.

### Technology and entry points
The primary implementation language is **Rust**. Users can install prebuilt binaries or packages through common Linux, BSD, macOS, and Windows package managers, including `apt`, `apk`, `pacman`, `dnf`, `brew`, MacPorts, Nix, WinGet, Chocolatey, and Scoop. Release binaries are available from the GitHub Releases page. Building from source requires Rust **1.79.0 or newer** and uses Cargo, for example:

```bash
cargo install --locked bat
```

A local checkout can be built or installed with `cargo build --bins`, `cargo test`, and `cargo install --path . --locked`. The main runtime entry point is the installed `bat` executable; on some older Debian or Ubuntu systems it may be installed under the name `batcat` because of a package-name conflict.

### Important README limitations and caveats
- Automatic syntax detection for standard input is limited: highlighting works only when the language can be inferred, commonly from a shebang on the first line, or when the language is specified explicitly.
- UTF-8 and UTF-16 are supported natively; other encodings may need to be converted to UTF-8 first.
- Input containing ANSI escape sequences or other control characters can produce garbled highlighting or wrapping. The README recommends stripping ANSI data or disabling color and wrapping; sanitization options are available for untrusted input.
- The quality of colors depends on terminal support. The README recommends 24-bit truecolor terminals for most themes or dedicated 8-bit themes for restricted terminals.
- On Windows, the Visual C++ Redistributable is required. Paging and color behavior may require installing or configuring `less`; Cygwin Unix-style paths are not natively supported without a wrapper.
- Installing from source with Cargo does not automatically install the man page or shell-completion files, although completions can be generated with `bat --completion <shell>`.
- Custom themes currently must use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported.
- The README notes that the bundled Manpage syntax still needs improvement.
- No recommended snap package is currently available, and existing unofficial packages are not officially supported.
- Git and diff presentation is available, but the README points users seeking more extensive Git/diff functionality toward the separate `delta` project.
