Project Overview
**bat** (`sharkdp/bat`) is a Rust command-line utility that serves as an enhanced `cat(1)` replacement. It prints files and standard input with syntax highlighting, line numbers, file headers, Git modification markers, configurable themes and styles, and automatic paging for output that exceeds the terminal height. When output is redirected or piped, it can fall back to plain file contents for compatibility with Unix pipelines.

Its main capabilities include displaying one or multiple files, concatenating files, reading from stdin, detecting or explicitly selecting a language, highlighting non-printable characters, showing Git changes, configuring themes and output decorations, generating shell completions, and integrating with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and `xclip`. It can also be used as a library for pretty-printing features. Typical users are developers, system administrators, and terminal-oriented users who inspect source code, configuration files, logs, command output, or Git revisions directly from a shell.

The primary technology is Rust. The main execution entry point is the installed `bat` executable, invoked with commands such as `bat README.md`; source builds use Cargo, requiring Rust 1.79.0 or newer, with `cargo install --locked bat` or `cargo install --path . --locked`. Prebuilt binaries and packages are documented for Linux distributions, macOS, Windows, BSD, Homebrew, MacPorts, Nix, and other package managers. On some older Debian or Ubuntu systems the executable is named `batcat`, and Windows installations require the Visual C++ Redistributable.

The repository is public, not archived, and its metadata reports a recent update on 2026-09-12, indicating ongoing maintenance. The README identifies the project as dual-licensed under MIT or Apache License 2.0, at the user's option; repository metadata separately labels the license `Apache-2.0`. Maintainers listed in the README are sharkdp, eth-p, keith-hall, and Enselic.

Important documented limitations include: stdin syntax highlighting may only be detected from the first line, non-interactive output is generally plain unless color and decorations are forced, UTF-8 and UTF-16 are supported natively while other encodings may need conversion, terminal themes work best with 24-bit truecolor or specially designed 8-bit themes, and input containing ANSI escape sequences or control characters can produce garbled output unless sanitization or stripping options are used. Cygwin Unix-style paths are not natively supported by the Windows binary. Custom themes currently require `.tmTheme` files, the bundled manpage syntax still needs work, and no snap package is officially recommended. The README also notes that installing from Cargo does not automatically install manpage or shell-completion files.
