sharkdp/bat, usually invoked as `bat`, is a Rust command-line utility that serves as an enhanced `cat(1)` replacement. Its purpose is to display, concatenate, and pipe file contents while adding syntax highlighting, configurable themes and output decorations, line numbers, Git change markers, automatic paging, and support for identifying or explicitly selecting many programming and markup languages. It can also show non-printable characters, read from standard input, generate shell completions, and expose pretty-printing functionality for applications that use it as a library.

Typical uses include inspecting source code and configuration files in a terminal, previewing files through `fzf`, `find`, or `fd`, viewing `git show` and diff-related output, colorizing manual pages or command help, monitoring logs with `tail -f`, and replacing `cat` in interactive shell workflows. The intended users are software developers, system administrators, and terminal users who want a more readable file viewer without giving up `cat`-style piping and concatenation behavior.

The primary technology is Rust. The main execution entry point is the `bat` executable, used with commands such as `bat README.md`, `bat src/*.rs`, or `curl ... | bat`. It can be installed from distribution packages on several Linux and BSD systems, Homebrew or MacPorts on macOS, Windows package managers such as WinGet, Chocolatey, and Scoop, Nix, prebuilt release binaries, or crates.io.
