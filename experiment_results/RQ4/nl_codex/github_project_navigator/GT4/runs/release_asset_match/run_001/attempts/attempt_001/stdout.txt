Project summary:
**bat** (`sharkdp/bat`) is a Rust command-line utility designed as a more capable replacement for POSIX `cat`. It displays files or standard input in the terminal with syntax highlighting, line numbers, file headers, Git modification markers, visible non-printable characters, configurable output styles, and automatic paging. When its output is redirected, it normally emits plain file contents so it can still be used for concatenation and in pipelines.

Typical uses include inspecting source and markup files, previewing `fzf`, `find`, or `fd` results, viewing Git revisions and diffs, following highlighted logs, colorizing help or man pages, and substituting for `cat` in interactive shell workflows. It is primarily intended for developers, system administrators, and other terminal users. It can also be used as a Rust library for pretty-printing, although library consumers must enable either the `regex-onig` or `regex-fancy` feature.

The main execution entry point is the `bat` command, for example `bat README.md`, `bat src/*.rs`, or `command | bat -l json`. Some older Debian and Ubuntu packages install it as `batcat`. Installation is available through many operating-system package managers, prebuilt GitHub release binaries, or Rust tooling with `cargo install --locked bat`. A local checkout requires Rust 1.79.0 or newer and can be installed with `cargo install --path . --locked`; development builds and tests use `cargo build --bins` and `cargo test`. Windows additionally requires the Visual C++ Redistributable.
