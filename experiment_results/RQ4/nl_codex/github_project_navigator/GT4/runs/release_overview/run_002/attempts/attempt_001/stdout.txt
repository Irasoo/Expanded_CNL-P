bat (sharkdp/bat) is a Rust command-line utility described as a “cat(1) clone with wings.” It is intended for developers, system administrators, and other terminal users who want to inspect or concatenate files with richer presentation than POSIX cat while retaining practical compatibility with pipelines.

Its main capabilities include syntax highlighting for many programming and markup languages, Git-aware change markers, optional line numbers and file headers, visualization of non-printable characters, automatic paging for long output, configurable themes and output styles, and support for custom Sublime Text syntax definitions and .tmTheme files. When output is redirected to another process or file, bat normally emits plain content so that it can serve as a cat replacement. It can also read standard input and integrate with tools such as fzf, find/fd, ripgrep-related wrappers, tail, git, xclip, man, and code formatters. A Rust library API is available for applications that need bat’s pretty-printing features.

Typical uses include viewing source or configuration files, previewing files in fuzzy finders, displaying highlighted logs, reading man pages or command help with color, inspecting Git revisions and nearby changes, concatenating files, and embedding highlighted output in terminal workflows.

The primary implementation language is Rust. The main execution entry point is the bat command, although some older Debian and Ubuntu packages install it as batcat because of a package-name conflict. Basic use is `bat README.md`, and input can also be piped to it. Installation is available through package managers on major Linux and BSD distributions, Homebrew or MacPorts on macOS, and WinGet, Chocolatey, or Scoop on Windows.
