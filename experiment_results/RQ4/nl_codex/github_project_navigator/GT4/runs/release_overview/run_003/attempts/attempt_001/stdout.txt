**Project Overview**

`bat` is a Rust-based command-line utility from `sharkdp/bat` that acts as an enhanced `cat(1)` replacement. It displays one or more files, standard input, or concatenated input while adding syntax highlighting, line numbers, file headers, Git modification markers, configurable decorations, and automatic paging. It is designed to preserve `cat`-style behavior when output is redirected or piped to another process.

**Core Capabilities and Use Cases**

Typical uses include inspecting source code and markup in a terminal, previewing files through tools such as `fzf`, `find`, `fd`, and `ripgrep`, viewing logs with `tail -f`, colorizing `man` pages and command help, reviewing Git content and diffs, and using it as a readable replacement for `cat`. Users can select languages and themes, configure output styles and pagers, show non-printable characters, control wrapping and tab expansion, define file-type associations, and add custom Sublime syntax definitions or themes.

The intended users are terminal-oriented developers, system administrators, and other command-line users who want readable file previews without giving up the normal file concatenation and pipeline workflows associated with `cat`.

**Technology and Entry Points**

The primary technology is Rust. End users run the installed `bat` executable, for example `bat README.md`, `bat src/*.rs`, or `curl ... | bat`. **Important Limitations and Caveats**

- Syntax highlighting for standard input can only be detected automatically when the language is inferable from the first line, commonly through a shebang; otherwise the language must be specified explicitly.
- When output is redirected or piped, `bat` normally emits plain file contents and suppresses terminal-oriented decorations unless options such as `--color=always` or `--decorations=always` are used.
- UTF-8 and UTF-16 are supported natively, but other encodings may need conversion to UTF-8 first.
- Inputs containing ANSI escape sequences or other control characters can produce garbled highlighting or wrapping; the README documents stripping and sanitizing options for such input.
- Windows users need the Visual C++ Redistributable. Native Windows `bat` does not directly support Cygwin-style `/cygdrive/*` paths without a wrapper or path conversion, and some installations use the executable name `batcat` rather than `bat`.
- Most syntax themes work best with terminals that support 24-bit truecolor; restricted terminals may need one of the documented 8-bit themes.
- Custom themes currently must use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported. The README also notes that the bundled Manpage syntax still needs work.
- Installing through Cargo does not automatically install auxiliary files such as the man page or shell completion files; completions can be generated separately with `bat --completion <shell>`.
