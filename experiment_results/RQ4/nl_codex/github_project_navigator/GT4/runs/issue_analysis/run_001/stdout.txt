Project summary:
`bat` is a cross-platform command-line utility from `sharkdp` that improves on the traditional POSIX `cat` command. Its purpose is to display and concatenate files in terminals while adding syntax highlighting, line numbers, file headers, Git modification markers, configurable themes and styles, automatic paging, non-printable-character visualization, and support for reading from standard input. When output is redirected or piped, it can fall back to plain file contents so it remains useful as a `cat` replacement.

Core capabilities include highlighting many programming and markup languages, selecting or extending syntax definitions and themes, showing Git changes relative to the index, controlling colors and decorations, configuring tabs and pagers, generating shell completions, and integrating with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `xclip`, `man`, and code formatters. Typical uses include inspecting source files, previewing search results, viewing logs and command help, reading files through pipelines, reviewing Git-related changes, and serving as a colorizing pager for manual pages. The intended users are developers, system administrators, and terminal-focused users who want readable file output without giving up normal `cat`-style pipelines.

The primary technology is Rust. Syntax highlighting is built around the `syntect` library and Sublime Text syntax and theme formats. The normal execution entry point is the installed `bat` executable, with commands such as `bat README.md`, `bat --help`, `bat --list-languages`, and `bat --completion <shell>`. Installation is available through operating-system package managers including `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `pkg_add`, `nix`, `zypper`, Homebrew, MacPorts, WinGet, Chocolatey, and Scoop; prebuilt binaries are available from GitHub releases. From source, the README requires Rust 1.79.0 or newer and supports `cargo install --path . --locked` or `cargo install --locked bat`. Development uses `cargo build --bins` and `cargo test`, with a recursive Git clone recommended for obtaining submodules.

The repository is not archived and the supplied metadata reports an update on 2026-09-12, indicating that it is maintained rather than discontinued.
