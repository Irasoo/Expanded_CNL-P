Project summary:
## Project Overview

**bat** is a Rust command-line utility that acts as an enhanced `cat(1)` replacement. It prints one or more files, standard input, or concatenated input while adding syntax highlighting, line numbers, file headers, Git change markers, configurable visual styles, and automatic paging for interactive output.

### Core Capabilities

- Syntax highlighting for many programming, markup, configuration, and text languages through the `syntect` library.
- Git integration that marks lines modified relative to the index.
- Automatic paging, using `less` or the built-in pager, when output is too large for the terminal.
- Plain `cat`-like behavior when output is redirected or piped to another process.
- Display of line numbers, grids, file names, file sizes, separators, and non-printable characters.
- Theme, style, pager, tab-width, color, wrapping, and decoration customization through command-line options, environment variables, or configuration files.
- Automatic or explicitly selected syntax detection for files and standard input.
- Custom syntax definitions and themes, with cache management commands.
- Shell completion generation and support for use with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `man`, and formatting utilities.

### Typical Use Cases

Users commonly run `bat README.md` or `bat src/*.rs` to inspect files in a terminal, use it as a visually enhanced replacement for `cat`, preview files from `fzf` or `fd`, inspect Git versions and diffs, colorize manual pages or command help, monitor logs with `tail -f`, and pipe formatted or highlighted output into other terminal tools. It can also be used as a Rust library for applications that need its pretty-printing features.

### Intended Users

The project is intended primarily for developers, system administrators, terminal users, and people who regularly inspect source code, configuration files, logs, documentation, command output, or Git changes from a command line. It supports Linux, macOS, Windows, BSD systems, and other platforms with suitable packages or binaries.

### Technology and Entry Points

The primary implementation language is **Rust**. Users can install prebuilt binaries or platform packages, including `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `pkg_add`, Nix, Homebrew, MacPorts, WinGet, Chocolatey, and Scoop. Releases also provide binaries for multiple architectures.

From source, Rust **1.79.0 or newer** is required. The main installation commands are `cargo install --path . --locked` for a local checkout and `cargo install --locked bat` from crates.io. Developers can clone the repository recursively, build with `cargo build --bins`, run tests with `cargo test`, and install a release build with Cargo. The executable entry point is the `bat` command. On some older Debian or Ubuntu systems it may be installed under the name `batcat` because of a package-name conflict.

### Important Limitations and Notes

- Automatic syntax detection for standard input only works when the syntax can be inferred from the first line, commonly through a shebang. Otherwise, specify the language with `-l` or `--language`.
- When output is piped or redirected, bat normally emits plain file contents and disables terminal-oriented decorations unless explicitly forced.
- UTF-8 and UTF-16 are supported natively. Other encodings may need to be converted to UTF-8 first.
- Inputs containing ANSI escape sequences or other control characters can produce garbled highlighting or wrapping. The README documents stripping and sanitizing options for such input.
- Most themes work best with terminals supporting 24-bit truecolor. Restricted terminals may need one of the provided 8-bit themes.
- On Windows, the Visual C++ Redistributable is required. Cygwin Unix-style `/cygdrive/*` paths are not natively supported and require a wrapper or path conversion.
- Custom themes currently must use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported.
- The bundled Manpage syntax is explicitly described as still needing work.
- Installing from source or crates.io with Cargo does not automatically install auxiliary files such as the man page and shell completions.
- The README points users seeking more extensive Git and diff support toward the separate `delta` project and points to `bat-extras` for additional wrappers.
