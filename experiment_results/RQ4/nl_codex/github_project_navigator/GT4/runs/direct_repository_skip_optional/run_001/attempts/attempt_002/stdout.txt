`bat` is a Rust command-line utility from `sharkdp/bat` that provides an enhanced, mostly drop-in replacement for POSIX `cat`. It displays one or more files or standard input in the terminal, adding syntax highlighting, line numbers, file headers, Git modification markers, configurable styles and themes, non-printable-character highlighting, tab expansion, and automatic paging for output larger than one screen. When output is redirected or piped, it falls back to plain file contents so it can be used in shell pipelines and file concatenation.

Typical uses include inspecting source code, configuration, markup, logs, and documentation; previewing files through `fzf`, `find`, or `fd`; viewing Git revisions and diffs; colorizing `man` pages and command help; monitoring logs with `tail -f`; and formatting output from other command-line tools. Its intended users are terminal-based developers, system administrators, and other command-line users who want readable file inspection while retaining `cat`-style pipeline behavior. The primary technology is Rust, with syntax definitions and themes based on Sublime Text-compatible formats through the `syntect` library.

The main execution entry point is the installed `bat` executable, with commands such as `bat README.md`, `bat file1 file2`, or `command | bat`. It can be installed from distribution packages on several Linux and BSD systems, Homebrew or MacPorts on macOS, WinGet, Chocolatey, or Scoop on Windows, Nix, release binaries, or from source with Rust 1.79.0 or newer using `cargo install --locked bat` or `cargo install --path . --locked`.
