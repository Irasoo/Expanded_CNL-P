**Project:** `bat` (`sharkdp/bat`)

**Purpose:** `bat` is a Rust command-line utility designed as a visually enhanced, mostly drop-in replacement for POSIX `cat`. It displays files and standard input with syntax highlighting, optional formatting decorations, and Git-aware change markers.

**Core capabilities:**
- Syntax highlighting for many programming, markup, configuration, and other text languages.
- Automatic or explicitly selected language detection.
- Git integration that shows modifications relative to the Git index.
- Line numbers, file headers, grids, file separators, change markers, and other configurable decorations.
- Automatic paging for output that exceeds the terminal height, with support for `less`, a built-in pager, or another configured pager.
- Display and highlighting of non-printable characters.
- Plain-output and non-interactive modes that make it suitable for pipelines and file concatenation.
- Theme, style, tab-width, syntax-association, pager, and configuration-file customization.
- Support for adding custom Sublime Text syntax definitions and `.tmTheme` themes.
- Shell completion generation and library/API use for applications that need its pretty-printing features.

**Typical use cases:** Users commonly invoke it to inspect source files, view several files together, preview search results through `fzf`, `find`, or `fd`, colorize `git`, `man`, and command help output, monitor logs with `tail -f`, view historical files from `git show`, and produce readable Git diff context. It can also continue to behave like `cat` when its output is redirected or piped.

**Intended users:** Developers, system administrators, terminal-focused users, and anyone who regularly reads source code, configuration files, logs, documentation, or command output from a shell.

**Primary technology:** Rust. The project uses the `syntect` ecosystem for Sublime Text-compatible syntax definitions and themes. Its repository topics identify it as a CLI, terminal, Git, and syntax-highlighting tool.

**Installation and execution entry points:** Prebuilt packages or binaries are available through common Linux and BSD package managers, Homebrew, MacPorts, Nix, Windows package managers such as WinGet, Chocolatey, and Scoop, and the GitHub release page. From source, the README requires Rust 1.79.0 or newer and documents `cargo install --path . --locked` for a local checkout or `cargo install --locked bat` from crates.io.
