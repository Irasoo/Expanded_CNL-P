## bat

**bat** is a Rust command-line utility positioned as an enhanced, drop-in replacement for POSIX `cat`. It displays one or more files, standard input, or concatenated streams with syntax highlighting, line numbers, file headers, Git modification markers, non-printable-character highlighting, and optional paging. Its output automatically becomes plain file content when redirected or piped to another process, preserving compatibility with typical Unix command pipelines.

Core capabilities include syntax detection and highlighting for many programming and markup languages, Git-aware change indicators, configurable themes and output decorations, automatic paging through `less` or a built-in pager, line-range and line-number controls, tab expansion, custom syntax and file-type mappings, shell-completion generation, and configuration through command-line options, environment variables, or a configuration file.
