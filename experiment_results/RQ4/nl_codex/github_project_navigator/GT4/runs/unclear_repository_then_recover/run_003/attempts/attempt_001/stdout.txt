Core capabilities include syntax highlighting for many programming and markup languages, automatic or explicitly selected language detection, line numbers, file headers, grid and change markers, highlighting of non-printable characters, configurable themes and output styles, tab expansion, file-type mappings, automatic paging, and configuration-file support. It is primarily intended for developers, system administrators, and terminal users who regularly inspect text files and command output.

The primary technology is Rust. The main execution entry point is the `bat` command-line executable.
