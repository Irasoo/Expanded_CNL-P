Project summary:
**Project:** `bat` (`sharkdp/bat`)

**Purpose:** A command-line `cat(1)` replacement that displays files with syntax highlighting, Git change markers, and terminal-friendly formatting.

**Core capabilities:**
- Syntax highlighting for many programming and markup languages
- Git integration showing modifications relative to the index
- Line numbers, file headers, grids, and non-printable-character display
- Automatic paging for interactive output
- Plain `cat`-style behavior when output is redirected or piped
- Reading files, multiple files, and standard input
- Configurable themes, styles, syntax mappings, pager, tab width, and shell completions
- Integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, and `man`

**Typical use cases:** Inspecting source code and configuration files, previewing search results, viewing logs, colorizing piped command output, reviewing Git changes, and replacing or augmenting `cat` in terminal workflows.

**Intended users:** Inferred from the README: terminal and command-line users, especially developers and system users who regularly inspect text, source code, logs, or Git output.

**Primary technology:** Rust. The main executable is the `bat` CLI; the README also documents using its pretty-printing features as a Rust library.
