## `bat`

**Purpose:** `bat` is a Rust command-line replacement for `cat`, adding syntax highlighting, Git change markers, line numbers, file headers, and terminal-friendly presentation.

**Core capabilities:**
- Syntax highlighting for many programming and markup languages
- Git integration showing modifications relative to the index
- Automatic paging for output larger than one terminal screen
- File concatenation and stdin support
- Display of non-printable characters
- Configurable themes, styles, decorations, syntax mappings, tabs, and pagers
- Plain-output mode for scripting and piping
- Custom syntax and theme support through Sublime Text definitions
- Shell-completion generation

**Typical use cases:** Viewing source code and markup, previewing files through `fzf` or `fd`, colorizing `man` pages and command help, inspecting Git output, monitoring logs with `tail -f`, and using it as a drop-in `cat` replacement.

**Intended users:** Terminal users, developers, and system administrators who want enhanced interactive file viewing while retaining `cat`-compatible behavior for redirected or piped output.

**Technology:** Rust; the README identifies `syntect` as the syntax-highlighting library.

**Execution and installation entry points:**
- Run the installed CLI with commands such as `bat README.md`, `bat src/*.rs`, or `bat -`
- Install packages through `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `pkg_add`, Nix, Homebrew, MacPorts, `winget`, Chocolatey, or Scoop
- Download prebuilt binaries from the GitHub release page
- Build from source with Rust 1.79.0 or newer using `cargo install --locked bat` or `cargo install --path . --locked`
- Development commands include `cargo build --bins` and `cargo test`

**License:** The repository metadata lists Apache-2.0. The README states that the project is available under either the MIT License or Apache License 2.0, at the user’s option.

**Important README limitations and caveats:**
- There is no recommended official Snap package; existing packages are unsupported.
- Older Debian and Ubuntu packages may install the executable as `batcat` rather than `bat`.
- On Windows, the Visual C++ Redistributable is required. Cygwin Unix-style paths are not natively supported.

- ANSI escape sequences and control characters can produce garbled highlighting or wrapping unless stripped, sanitized, or disabled.
