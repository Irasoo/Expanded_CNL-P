**Project:** `bat` (`sharkdp/bat`)

**Purpose:** A Rust-based `cat(1)` clone that adds syntax highlighting, Git change markers, line numbers, and terminal-friendly output while retaining `cat`-style file and stdin handling.

**Core capabilities:**

- Git integration that displays modifications relative to the index.
- Automatic paging for large interactive output.
- File concatenation, stdin processing, line numbers, non-printable-character highlighting, and configurable output styles.
- Custom themes, syntax definitions, file-type mappings, pager settings, and shell completions.
- Integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `tail`, `man`, and `xclip`.

**Typical use cases:** Inspecting source code and configuration files, previewing search results, viewing Git content and diffs, colorizing man pages or command help, monitoring logs, and using `bat` as a visually enhanced `cat` replacement.

**Intended users:** Command-line users, software developers, system administrators, and others who inspect text files or terminal output.

**Primary technology:** Rust. The project also uses the `syntect` library for syntax highlighting and supports use of its pretty-printing features as a library.

**Execution and installation entry points:**
- Run the installed `bat` executable, for example `bat README.md`.

- Install prebuilt binaries from the GitHub Releases page.
- Build from source with Rust 1.79.0 or newer using `cargo install --path . --locked` or `cargo install --locked bat`.
