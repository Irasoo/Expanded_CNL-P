Project summary:
**Project:** `bat` (`sharkdp/bat`)

**Purpose:** A Rust command-line clone of `cat(1)` that adds syntax highlighting, Git-aware change markers, readable terminal formatting, and paging while retaining cat-like behavior.

**Core capabilities:**
- Syntax highlighting for many programming and markup languages
- Git modification markers
- Line numbers, file headers, grids, wrapping, and configurable output styles
- Automatic paging through `less` or a built-in pager
- Display of non-printable characters
- Reading files, multiple files, or standard input
- Theme, syntax, file-association, pager, and configuration-file customization
- Shell-completion generation and integrations with tools such as `fzf`, `find`, `fd`, `ripgrep`, `git`, `man`, and `tail -f`

**Typical use cases:** Inspecting source code and configuration files, previewing files in `fzf` or search results, viewing Git revisions and diffs, colorizing manual pages or command help, monitoring logs, concatenating files, and replacing `cat` in interactive shell workflows.

**Intended users:** Terminal users, software developers, system administrators, and others who regularly inspect or pipe text files from a command line.

**Primary technology:** Rust. The project uses the `syntect` library for syntax definitions and themes and integrates with Git and terminal pagers.

**Installation and execution entry points:**
- Run the installed executable as `bat`; some older Debian/Ubuntu packages use `batcat`.
- Install through system package managers such as `apt`, `apk`, `pacman`, `dnf`, `emerge`, `pkg`, `nix`, Homebrew, MacPorts, WinGet, Chocolatey, or Scoop.
- Install prebuilt binaries from the GitHub Releases page.
- Build from source with Rust 1.79.0 or newer using `cargo install --path . --locked` or `cargo install --locked bat`.
- Build and test from a checkout with `cargo build --bins` and `cargo test`.

**License:** Repository metadata identifies Apache-2.0. The README states that `bat` is available under either the MIT License or Apache License 2.0, at the user’s option.

**Maintenance status:** The repository is not archived. Its supplied metadata lists an update on `2026-09-12`.

**Important README limitations and caveats:**
- Syntax detection for stdin only works when the language can be inferred from the first line, commonly through a shebang; otherwise specify `-l`.
- Non-interactive output is automatically emitted as plain file contents, so terminal decorations and paging behavior differ when piping.
- UTF-8 and UTF-16 are supported natively; other encodings may need conversion to UTF-8 first.

- Rich themes work best with 24-bit truecolor terminals; restricted terminals may require the included 8-bit themes.
- Windows requires the Visual C++ Redistributable, and native Windows `bat` does not directly support Cygwin-style `/cygdrive/*` paths.
