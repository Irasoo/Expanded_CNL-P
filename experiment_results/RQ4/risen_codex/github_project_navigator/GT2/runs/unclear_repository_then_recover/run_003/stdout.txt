=== Project summary ===
bat is a Rust command-line cat(1) replacement with syntax highlighting and Git integration. It displays one or more files or standard input with configurable colors, themes, line numbers, file headers, Git-change markers, non-printable-character visibility, wrapping, and automatic paging, and can generate shell completions and serve as a previewer or formatter component in terminal workflows. Typical uses include reading source and markup files, reviewing changes, previewing find/fd or fzf results, colorizing git, man, and command-help output, monitoring logs, and concatenating files in pipelines. It is intended for developers, system administrators, and terminal users who want more readable file inspection while retaining cat-like behavior. The primary technology is Rust; users can install it through OS package managers, Homebrew, MacPorts, WinGet, Chocolatey, Scoop, Nix, prebuilt release binaries, or Cargo, and build or install from source with Rust 1.79.0 or newer using cargo. The README states that it is dual-licensed under MIT or Apache-2.0; the repository metadata lists Apache-2.0. The project is not archived, identifies maintainers, documents testing and contribution procedures, and has a recorded update date of 2026-09-12, indicating ongoing maintenance in the supplied data.
