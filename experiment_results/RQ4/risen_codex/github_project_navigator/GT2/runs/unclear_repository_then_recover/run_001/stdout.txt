=== Project summary ===
bat is a Rust command-line cat(1) replacement for developers, system administrators, and terminal users who want readable file and stream output. It provides syntax highlighting for many programming and markup languages, Git change markers, line numbers and other configurable decorations, automatic paging, non-printable-character display, theme and syntax customization, stdin/pipeline support, and integrations with tools such as fzf, find/fd, ripgrep, git, tail, man, and xclip. Typical uses include inspecting source or configuration files, previewing search results, viewing diffs and logs, colorizing help or man pages, and concatenating files while retaining cat-like behavior for non-interactive output. It is primarily written in Rust and is executed as the bat binary; installation entry points include distribution packages, Homebrew or MacPorts, Windows package managers and releases, prebuilt binaries, or Rust/Cargo commands such as cargo install --locked bat and cargo install --path . --locked from source. The README states that it is dual-licensed under MIT or Apache License 2.0, although the supplied repository metadata lists Apache-2.0. The repository is not archived, identifies maintainers, documents tests and development commands, and has a recent recorded update, indicating ongoing maintenance. Important limitations and caveats include incomplete or difficult syntax detection for some stdin and streaming cases, native encoding support focused on UTF-8 and UTF-16, possible garbled output for ANSI or control-character-containing input, dependence on terminal color and pager behavior, extra Windows/Cygwin configuration requirements, no recommended officially supported snap package, and a README note that man-page syntax still needs work. Cargo installation does not automatically install man pages or shell-completion files.
