=== Project summary ===
bat (sharkdp/bat) is a Rust-based command-line cat(1) replacement for developers, system administrators, and terminal users who want readable file and stream inspection. It provides syntax highlighting for many programming and markup languages, Git modification markers, line numbers and other configurable decorations, automatic paging, non-printable-character display, stdin and multi-file support, themes, custom syntax and file associations, and integration with tools such as fzf, find/fd, ripgrep, git, man, and tail. Typical uses include viewing source code and configuration files, previewing search results, inspecting diffs, colorizing man pages and help output, and safely displaying potentially untrusted text with sanitization options. The main entry point is the bat executable; users can install prebuilt packages or binaries through common Linux, BSD, macOS, and Windows package managers, or build/install from source with Rust and cargo (for example, cargo install --locked bat). The README also documents cargo build/test development commands and a library API. The repository is not archived and lists maintainers, contribution, and security documentation; its supplied metadata records an update on 2026-09-12, indicating ongoing maintenance. Although the metadata identifies Apache-2.0, the README states that bat is offered under either the MIT License or Apache License 2.0, at the user's option. Important limitations and caveats include incomplete Manpage syntax support, no officially supported snap package, extra Windows prerequisites and pager configuration, no native Cygwin-style absolute-path support, possible garbled output for ANSI/control-code input, native encoding support focused on UTF-8 and UTF-16, reduced color quality without truecolor terminals, limited automatic syntax detection for some stdin streams, and missing automatic installation of man pages and shell completions when installed with cargo.
