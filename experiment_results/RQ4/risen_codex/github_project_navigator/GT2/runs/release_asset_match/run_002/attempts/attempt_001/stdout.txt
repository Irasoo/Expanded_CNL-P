=== Project summary ===
bat (sharkdp/bat) is a Rust-based command-line utility that serves as an enhanced cat(1) replacement for viewing and concatenating files. Its core capabilities include syntax highlighting for many programming and markup languages, Git change markers, line numbers and other configurable decorations, automatic paging, display of non-printable characters, stdin support, themes, syntax and file-type customization, and configurable pagers. It is intended for developers, system administrators, and terminal users, with common uses including inspecting source code and configuration files, previewing find/fd results in fzf, viewing diffs and help or man pages, monitoring logs, and formatting piped text. The primary executable is bat; users can install it from OS package managers, Homebrew, MacPorts, WinGet, Chocolatey, Scoop, Nix, releases, or build and install it with Rust and Cargo using cargo install --locked bat or cargo install --path . --locked. The repository is not archived and lists maintainers, development commands, and security guidance, indicating ongoing maintenance; the supplied metadata records a recent update. Licensing is dual MIT or Apache License 2.0, while the repository metadata identifies Apache-2.0. Important README limitations include incomplete Manpage syntax support, no officially supported snap package, weak automatic detection for some stdin cases and non-UTF-8 encodings, possible garbled output for ANSI or control-character input, a need for truecolor terminals or simpler themes for best colors, extra Windows prerequisites and limited Cygwin path support, and the fact that source installation does not automatically install man pages or shell completions.
