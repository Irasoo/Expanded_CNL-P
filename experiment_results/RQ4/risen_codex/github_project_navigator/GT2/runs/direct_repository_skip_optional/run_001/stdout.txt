=== Project summary ===
bat is a Rust-based command-line cat(1) replacement that displays files with syntax highlighting, line numbers, Git change markers, configurable themes and styles, non-printable-character highlighting, and automatic or configurable paging. It is intended for developers, system administrators, and terminal users who inspect source code, markup, logs, configuration files, command output, search results, diffs, or man pages, and it can be integrated with tools such as fzf, find/fd, ripgrep, tail, and git. The primary entry point is the `bat` executable; users can install packaged versions through common Linux, BSD, macOS, and Windows package managers, download release binaries, or build/install from source with Rust and `cargo install --locked` (the README specifies Rust 1.79.0 or newer). The repository is not archived and its supplied metadata reports a recent update, so it appears actively maintained. The code is licensed under either the MIT License or Apache License 2.0, while the repository metadata labels it Apache-2.0. README limitations include imperfect handling of ANSI/control sequences and potentially garbled output, native support focused on UTF-8 and UTF-16 with other encodings generally requiring conversion, syntax autodetection from stdin working reliably only when the first line provides enough information such as a shebang, best color results requiring truecolor terminals or compatible 8-bit themes, older Debian/Ubuntu packages sometimes installing the command as `batcat`, Windows requiring the Visual C++ Redistributable and having Cygwin-path limitations, no officially supported snap package, and custom themes currently requiring `.tmTheme` files.
