sharkdp/bat, named bat, is a Rust command-line cat(1) replacement for viewing and concatenating files with syntax highlighting, line numbers, Git change markers, non-printable-character display, configurable styling and themes, and automatic paging. It is intended for developers, system administrators, and terminal users who inspect source code, markup, logs, diffs, help text, or command output, and it integrates with tools such as Git, fzf, find/fd, ripgrep, tail, man, and clipboard utilities. The repository is not archived and was updated on 2026-09-12, indicating ongoing maintenance; the supplied data does not establish release quality from popularity or issue counts.
