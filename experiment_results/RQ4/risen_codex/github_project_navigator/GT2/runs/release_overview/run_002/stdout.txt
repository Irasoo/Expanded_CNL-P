sharkdp/bat is a maintained, non-archived Rust command-line utility that serves as a feature-rich cat(1) replacement for developers, system administrators, and terminal users. It displays files and standard input with syntax highlighting, configurable themes and styles, line numbers, automatic paging, non-printable-character visibility, and Git modification markers, and integrates with tools such as fzf, find/fd, ripgrep, man, and git. Typical uses include readable source-code inspection, file previewing, viewing diffs or help output, monitoring logs, and plain file concatenation in pipelines.
