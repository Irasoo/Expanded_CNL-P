=== Project summary ===
bat (sharkdp/bat) is a Rust command-line cat(1) replacement for developers and other terminal users who want readable file and pipeline output. Its core capabilities include syntax highlighting for many programming and markup languages, line numbers and other configurable decorations, Git modification markers, automatic paging, non-printable-character display, stdin and multi-file handling, themes, syntax and file-type customization, shell completions, and integration with tools such as fzf, find/fd, ripgrep, tail, git, man, and formatters. Typical uses include inspecting source code and documents, previewing search results, viewing diffs or man pages, monitoring logs, colorizing help output, and concatenating files while retaining cat-like behavior for non-interactive output. It is distributed as platform packages, Homebrew/MacPorts/Nix and Windows package-manager installations, prebuilt release binaries, or from source with Rust and Cargo (for example, `cargo install --locked bat`); the executable is the primary entry point. The project is not archived, identifies multiple maintainers, and provides contribution and security documentation; the supplied metadata records an update on 2026-09-12, supporting an actively maintained status without relying on popularity or issue counts. The README states that bat is available under either the MIT License or Apache License 2.0, although the repository metadata lists Apache-2.0. Important limitations and caveats include incomplete syntax auto-detection for stdin and streaming input, native encoding support focused on UTF-8/UTF-16, possible garbled output for ANSI or control-code input unless sanitization or stripping is used, best color results on truecolor terminals, lack of native Cygwin-style paths on Windows, a man-page syntax definition that still needs work, custom themes requiring `.tmTheme` files, and source installation not automatically installing man pages or shell completions; the README also says no snap package is currently recommended.
