=== Project summary ===
bat is a Rust-based command-line cat(1) replacement for developers, system administrators, and terminal users who want readable file and stream output. It provides syntax highlighting for many programming and markup languages, line numbers, configurable themes and styles, automatic paging, non-printable-character display, Git modification markers, stdin and multi-file handling, and integrations with tools such as fzf, find/fd, ripgrep, tail, git, man, and xclip. Typical uses include viewing source code and configuration files, previewing search results, inspecting Git versions or diffs, colorizing man pages and help text, and concatenating files in pipelines; it falls back to plain content for non-interactive output. The main executable is bat, runnable as `bat FILE` or from stdin, and it can be installed through distribution packages, Homebrew, MacPorts, Nix, Windows package managers, prebuilt releases, or Rust Cargo (`cargo install --locked bat`); source builds require Rust 1.79.0 or newer. The repository is not archived and its supplied metadata shows a recent update, although no stronger maintenance guarantee is stated. The README describes a permissive dual MIT/Apache-2.0 license, while repository metadata labels it Apache-2.0. Important limitations include weaker automatic syntax detection for stdin and streaming input, native encoding support focused on UTF-8 and UTF-16, possible garbled output for ANSI/control sequences unless sanitization or disabling highlighting/wrapping is used, best color results on truecolor terminals, incomplete support for Cygwin paths on Windows, possible `batcat` naming on older Debian/Ubuntu systems, no recommended officially supported Snap package, custom themes requiring `.tmTheme` files, and a man-page syntax definition that still needs work.
