=== Project summary ===
sharkdp/bat is a maintained, non-archived Rust command-line utility that serves as a cat(1) replacement with syntax highlighting, Git modification markers, line numbers and other configurable terminal decorations, automatic paging, non-printable-character display, and integrations with tools such as fzf, find, ripgrep, git, man, and tail. It is intended for developers, system administrators, and terminal users who want to inspect, preview, concatenate, or pipe source code, markup, logs, and other text more readably. Users run it through the bat executable, for example `bat README.md`, or install it from platform package managers, Homebrew, releases, crates.io with `cargo install --locked bat`, or source with Rust 1.79+ using `cargo install --path . --locked`. The README documents development through Cargo and identifies maintainers; repository data shows it is not archived and was updated on 2026-09-12. The project is licensed under either the MIT License or Apache License 2.0, although the supplied repository license field reports Apache-2.0. Important limitations include imperfect automatic syntax detection for stdin and some inputs, native encoding support focused on UTF-8 and UTF-16, possible garbled output from ANSI/control sequences, reduced color quality on terminals without truecolor support, extra Windows/Cygwin configuration requirements, a Debian/Ubuntu `bat` versus `batcat` naming issue, and no officially supported snap package. Custom themes must use `.tmTheme` files, and building from source does not automatically install man pages or shell completions.
