**Core capabilities.** `bat` displays one or more files, reads from standard input, and concatenates content when output is redirected or piped. In interactive terminals it can automatically page long output, show syntax highlighting for many programming and markup languages, display non-printable characters, and show file modifications relative to the Git index. Output styles, themes, decorations, line ranges, tab expansion, language selection, file-type associations, and pager behavior are configurable. It can be used as a `cat` replacement, but paging must be disabled when behavior identical to `cat` is required.
