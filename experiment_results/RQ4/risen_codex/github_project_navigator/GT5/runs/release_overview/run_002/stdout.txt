  - Optional line numbers, file headers, grids, separators, and non-printable-character display.
  - Automatic paging for interactive output, with plain file-content behavior when output is redirected or piped.
  - Reading files, multiple files, or standard input, with automatic or explicitly selected syntax.
  - Configurable themes, styles, pager behavior, tab expansion, syntax associations, and shell completions.

  - Options for stripping ANSI sequences and sanitizing potentially unsafe terminal control characters in untrusted input.
