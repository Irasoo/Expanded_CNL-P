# Project summary: `sharkdp/bat`

**`bat`** is an open-source command-line utility described as “a `cat(1)` clone with wings.” Its main purpose is to display files and standard input in a more readable, terminal-oriented format while retaining the basic file-concatenation role of POSIX `cat`.

## Core capabilities

According to the supplied repository facts and README, `bat` provides:

- Syntax highlighting for many programming and markup languages.
- Git integration that displays modifications relative to the index.
- Optional line numbers, file headers, grids, separators, and other output decorations.
- Automatic paging for output that exceeds one terminal screen, with support for `less` and a built-in pager.
- Automatic or explicitly selected syntax detection for files and piped input.
- Display of non-printable characters with `-A`/`--show-all`.
- Plain, colorized, or decorated output modes suitable for interactive terminals and pipelines.
- Theme, syntax-definition, file-association, pager, tab-width, and configuration-file customization.
- Shell-completion generation and support for use with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, and `man`.
- Optional sanitization and ANSI-stripping features for problematic or untrusted terminal input, as documented in the README.

These capabilities support the project’s stated goals: advanced syntax highlighting, Git-aware display, a user-friendly CLI, and compatibility as a drop-in replacement for `cat`.

- Sanitization is relevant for untrusted input because terminal-active control bytes and certain Unicode formatting characters may otherwise affect display.

- Custom themes must use `.tmTheme` files; newer `.sublime-color-scheme` files are not supported.
- Building or installing from source does not automatically install supplementary files such as the man page or shell completions.
