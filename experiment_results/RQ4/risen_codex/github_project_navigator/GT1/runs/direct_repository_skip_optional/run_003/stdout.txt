Project name: bat (sharkdp/bat). Core capabilities include syntax highlighting for many programming and markup languages, automatic or explicitly selected language detection, line numbers, file headers, configurable themes and output styles, Git modification markers, non-printable-character display, paging, stdin and multiple-file input, configuration files, shell completion generation, and optional sanitization or ANSI-stripping for untrusted or control-character-containing input. The primary technology is Rust; the README identifies syntect as the syntax-highlighting library and provides Cargo build and installation commands.
