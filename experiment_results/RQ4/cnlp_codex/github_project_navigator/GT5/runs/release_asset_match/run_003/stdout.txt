## sharkdp/bat — project overview

**bat** is a Rust command-line file viewer designed as a more user-friendly, mostly drop-in replacement for POSIX `cat`. It adds syntax highlighting, Git change markers, line numbers, file headers, non-printable-character display, and automatic paging while retaining plain concatenation behavior when output is redirected.

- **Typical uses:** inspecting source and markup files, previewing files in tools such as `fzf`, displaying piped command output, viewing Git revisions or diffs, monitoring highlighted logs, and colorizing man pages or `--help` text.
- **Intended users:** developers, terminal users, system administrators, and others who regularly inspect text or source files from a shell. A Rust library API is also documented for applications that need bat’s pretty-printing features.
