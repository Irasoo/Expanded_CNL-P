## `sharkdp/bat` overview

**bat** is a Rust command-line utility designed as a more presentation-oriented replacement for POSIX `cat`. It displays or concatenates files and standard input while adding syntax highlighting, Git change markers, line numbers, headers, and optional paging.

- **Core capabilities:** Highlights many programming and markup languages; shows Git modifications relative to the index; reveals non-printable characters; reads one or multiple files or stdin; supports concatenation; automatically pages long interactive output; and provides configurable themes, output styles, syntax mappings, and shell completions.
- **Typical uses:** Inspecting source or configuration files, previewing files in `fzf`, presenting search results, viewing `git show` output, monitoring logs with `tail -f`, colorizing man/help text, and acting as a mostly drop-in `cat` replacement in pipelines.
- **Intended users:** Developers, terminal users, system administrators, and others who regularly inspect text or source code from a shell. A Rust library API is also documented for applications that need bat’s pretty-printing features.
- **Primary technology:** Rust, using `syntect`-compatible Sublime Text syntax definitions and `.tmTheme` themes.
- **Entry points:** Run the installed executable as `bat`; on some older Debian/Ubuntu releases it may be named `batcat`. Installation is documented through numerous OS package managers, prebuilt release binaries, or Cargo (`cargo install --locked bat`). Building local source requires Rust 1.79.0 or newer and uses `cargo install --path . --locked` or `cargo build --bins` for development.

### Important README limitations

- Syntax detection from stdin may require a recognizable first line, such as a shebang, or an explicit `--language` option.
- Native encoding support is limited to UTF-8 and UTF-16; other encodings may need conversion.
- ANSI/control sequences in input can disrupt highlighting and wrapping unless stripping or sanitization options are used.
