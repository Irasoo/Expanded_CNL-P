## sharkdp/bat — project overview

**bat** is a Rust command-line file viewer and `cat(1)` alternative designed for more readable terminal output while retaining `cat`-like behavior in pipelines.

- **Core capabilities:** Syntax highlighting for many programming and markup languages, Git change markers, line numbers and file headers, display of non-printable characters, automatic paging, configurable themes/styles, and input from files or stdin.
- **Typical uses:** Inspecting source files, concatenating files, previewing search results with tools such as `fzf` or `find`, colorizing help/man output, monitoring logs, and viewing Git content.
- **Intended users:** Developers and terminal users who want a richer interactive file viewer or a mostly drop-in `cat` replacement.
- **Primary technology:** Rust; its highlighting uses `syntect` and supports Sublime Text `.sublime-syntax` definitions and `.tmTheme` themes. It can also be consumed as a Rust library.
- **Execution entry point:** The CLI command is `bat`; some older Debian/Ubuntu packages install it as `batcat`. Basic usage is `bat FILE`, with stdin also supported.
- **Installation/build entry points:** Documented package-manager options include `apt`, Homebrew, WinGet, Chocolatey, Scoop, and several Unix package managers. Official releases provide prebuilt binaries. Source installation uses `cargo install --locked bat` or, from a local checkout, `cargo install --path . --locked`; building requires Rust 1.79.0 or newer.
- **License:** The README offers a choice of MIT or Apache License 2.0. The repository metadata identifies Apache-2.0.

### Important README limitations

- Automatic syntax detection for stdin may require a recognizable first line, such as a shebang; otherwise the language should be specified explicitly.
- Automatic paging differs from normal `cat` behavior, though `--paging=never` disables it. When output is redirected, `bat` normally emits plain content.
- Cargo installation does not automatically install ancillary files such as man pages and shell completions.
- Windows requires the Visual C++ Redistributable; its bundled pager is limited, and native Cygwin-style absolute paths are unsupported without conversion or a wrapper.

- Truecolor is recommended for most themes; custom themes must use `.tmTheme`, not newer `.sublime-color-scheme` files.
