## Project overview

**sharkdp/bat** is a Rust command-line utility described as “a `cat(1)` clone with wings.” Its purpose is to display files and standard input in a more readable terminal format while remaining usable as a `cat` replacement. It adds syntax highlighting, line numbers and other output decorations, Git modification markers, automatic paging, configurable themes and styles, and support for showing non-printable characters.

### Capabilities and typical use

Typical uses include:

- Viewing one or multiple source, configuration, markup, or text files.
- Reading piped input from commands such as `curl`, formatters, `git show`, or `tail -f`.
- Previewing files with `fzf`, `find`, or `fd`.
- Displaying Git-aware file changes and colorizing `git diff` output.
- Acting as a colorizing pager for `man` pages or command help messages.
- Customizing syntax definitions, themes, file-type associations, paging, tab expansion, and output style.

The intended users are developers, system administrators, and terminal-oriented users who want enhanced file inspection and command-line workflow integration. The README also documents use of `bat` as a library, but its primary entry point is the `bat` executable.
