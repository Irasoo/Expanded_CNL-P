Project overview
## Project overview

**bat** (`sharkdp/bat`) is a Rust command-line utility described as a “cat(1) clone with wings.” It is intended to serve as a more readable, feature-rich replacement for `cat`, especially when viewing source code, markup, configuration files, logs, or command output in a terminal.

### Purpose and capabilities

Its core capabilities include:

- Syntax highlighting for many programming and markup languages.
- Git integration that displays file modifications relative to the Git index.
- Optional line numbers, file headers, grids, change markers, and other output decorations.
- Automatic paging for output that exceeds one terminal screen.
- Plain concatenation behavior when output is redirected or piped.
- Display and highlighting of non-printable characters.
- Automatic or explicitly selected language detection for files and standard input.
- Custom themes, syntaxes, file-type associations, pager settings, and configuration files.
- Integration with tools such as `fzf`, `find`, `fd`, `ripgrep`, `tail`, `git`, `xclip`, and `man`.
- Shell-completion generation and an API usable by applications that depend on its pretty-printing features.

Typical uses include interactively inspecting source files, previewing search results, colorizing piped data, viewing Git-related output, formatting terminal help text, and using `bat` as a pager or `cat` replacement. The primary users are developers, system administrators, and terminal users who want enhanced file viewing without giving up standard command-line piping and redirection workflows.

### Technology and entry points

The primary language is **Rust**. The main execution entry point is the `bat` command, for example `bat README.md` or `bat file1 file2`. The README documents installation through operating-system package managers, Homebrew, MacPorts, Nix, Snap-related guidance, Windows package managers, prebuilt release binaries, and Cargo. From source, it requires Rust **1.79.0 or newer** and can be installed with `cargo install --path . --locked`; the README also documents `cargo install --locked bat` from crates.io. Building and testing use Cargo commands such as `cargo build --bins` and `cargo test`.

The README notes that some Debian-based distributions install the executable as `batcat` because of a package-name conflict. It also says that source/Cargo installation does not automatically install the man page or shell-completion files, although completions can be generated with `bat --completion <shell>`.
