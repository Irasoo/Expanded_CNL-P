## Project overview

**bat** is a Rust command-line utility described as a “cat(1) clone with wings.” It is intended to make viewing text files more readable while retaining `cat`-style behavior when output is redirected or piped. Its main capabilities include syntax highlighting for many programming and markup languages, configurable themes and output decorations, line numbers, Git index-change markers, automatic paging, stdin support, file concatenation, and display of non-printable characters. It can also be used with tools such as `fzf`, `find`/`fd`, `ripgrep`, `tail`, `git`, `man`, and code-formatting wrappers.
