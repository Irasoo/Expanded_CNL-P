## Project overview

**bat** is a Rust command-line utility described as a `cat(1)` clone “with wings.” Its main purpose is to display files and streamed text in a more readable terminal interface while remaining usable as a `cat` replacement in pipelines.

### Purpose and capabilities

Core capabilities documented in the README include:

- Syntax highlighting for many programming and markup languages.
- Git integration that displays file modifications relative to the Git index.
- Optional line numbers, file headers, grids, change markers, wrapping, and non-printable-character visualization.
- Automatic paging for output that does not fit on one screen, using `less`, another configured pager, or its built-in pager.
- Plain, pipeline-friendly output when writing to a non-interactive terminal.
- Reading one or more files, standard input, or combinations such as files plus stdin.
- Custom themes, syntax definitions, file-type associations, pager settings, and configuration files.
- Shell, search, diff, `man`, `fzf`, and formatting-tool integrations through command usage and optional external wrappers such as `bat-extras`.

Typical uses include inspecting source code, configuration files, logs, Git changes, command help output, and manual pages. It is aimed primarily at developers, system administrators, and terminal users who want enhanced file viewing without giving up the familiar `cat` workflow. It can also be used by scripts and other command-line tools, but decorations, color, and paging may need to be disabled or forced depending on whether output is interactive.

### Technology and entry points

The primary technology is **Rust**. The main execution entry point is the `bat` executable. The README documents installation through distribution packages and package managers including `apt`, `apk`, `pacman`, `dnf`, Gentoo, FreeBSD, OpenBSD, Nix, openSUSE, Homebrew, MacPorts, WinGet, Chocolatey, and Scoop. It also documents prebuilt binaries from the GitHub Releases page and source installation through Cargo:

- `cargo install --locked bat` from crates.io.
- `cargo install --path . --locked` from a local source checkout.
- Development builds with `cargo build --bins`.

Building from source requires Rust **1.79.0 or newer**, according to the README. The README also states that Cargo-based installation does not automatically install additional files such as the man page or shell-completion files.
