## Project overview

**sharkdp/bat** is a Rust command-line utility whose name and description present it as a “cat(1) clone with wings.” It aims to be a drop-in replacement for POSIX `cat` while adding syntax highlighting, line numbers, Git modification markers, file decorations, and automatic paging.

### Core capabilities and use cases

`bat` displays one or more files, reads from standard input, concatenates files, and can show non-printable characters. It supports syntax highlighting for many programming and markup languages, configurable themes and output styles, language/file-type mappings, shell completions, and a configuration file. It can integrate with tools such as Git, `fzf`, `find`/`fd`, `ripgrep`, `tail`, `man`, and clipboard utilities.

Typical users include developers, system administrators, and terminal users who want a more readable file viewer, a syntax-highlighted pager or previewer, or a command that behaves like `cat` when output is redirected or piped. The primary technology is **Rust**; the README identifies `syntect` as the syntax-highlighting library and documents use both as a CLI and, with suitable features, as a library.

### Execution and installation entry points

The normal entry point is the installed `bat` executable, for example `bat README.md` or `bat -A /etc/hosts`. The README documents installation through system package managers on several Linux and BSD distributions, Homebrew or MacPorts on macOS, WinGet/Chocolatey/Scoop or release binaries on Windows, Nix, and prebuilt release binaries for multiple architectures. Building from source requires Rust **1.79.0 or newer** and uses Cargo, including `cargo install --locked bat` or `cargo install --path . --locked` from a local source tree. A source ZIP or tar archive should be treated as source code requiring such a build, not as an already installable binary.
