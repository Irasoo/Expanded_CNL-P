## Project overview

**Repository:** [`sharkdp/bat`](https://github.com/sharkdp/bat)

### Name and purpose
`bat` is a command-line file viewer named as a counterpart to Unix `cat`. Its tagline—“a cat(1) clone with wings”—refers to adding presentation and navigation features while retaining common `cat`-style input and concatenation behavior.

### Core capabilities
- Syntax highlighting for many programming and markup languages, powered by the Rust `syntect` library.
- Git integration that marks changes relative to the index.
- Optional line numbers, file headers, grids, change markers, and non-printable-character display.
- Automatic paging for output longer than the terminal, normally through `less`, with a built-in pager also available.
- Reading one or more files or standard input; when output is redirected, it normally emits plain content for `cat`-like pipeline behavior.
- Configurable themes, output styles, syntax mappings, pager behavior, tab width, decorations, and persistent configuration files.
- Integration patterns for tools such as `fzf`, `find`/`fd`, `ripgrep` wrappers, `tail`, Git, `man`, and clipboard utilities.
- A Rust library API for applications that want to use its pretty-printing functionality.

### Typical users and use cases
The primary audience is developers, system administrators, terminal users, and tool authors. Typical uses include interactively inspecting source or configuration files, previewing files in fuzzy finders, viewing Git-aware file output, colorizing streamed logs or command help, acting as a `man` pager, and replacing `cat` where enhanced terminal output is useful.

### Technology and entry points
The primary implementation language is **Rust**. The main runtime entry point is the `bat` CLI executable; on some older Debian or Ubuntu releases it may instead be installed as `batcat` because of a historical package-name collision.

The README documents installation through numerous operating-system package managers, including `apt`, Homebrew, WinGet, Chocolatey, Scoop, `dnf`, `pacman`, and others. It also points to prebuilt binaries on the repository’s Releases page. Windows installations require the Visual C++ Redistributable according to the README. Source installation is supported with Cargo and requires **Rust 1.79.0 or newer**:

- Local source: `cargo install --path . --locked`
- crates.io: `cargo install --locked bat`

Cargo installation does not automatically install ancillary files such as man pages and shell completions in every case. The CLI can generate supported shell completions with `bat --completion <shell>`.
