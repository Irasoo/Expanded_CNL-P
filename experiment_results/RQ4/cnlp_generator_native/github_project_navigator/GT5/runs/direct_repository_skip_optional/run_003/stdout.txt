Core capabilities include syntax highlighting for many programming and markup languages, Git modification markers, optional line numbers and file headers, visualization of non-printable characters, configurable themes and output styles, and automatic paging for output longer than the terminal screen. The project additionally exposes pretty-printing functionality as a Rust library.

The main execution entry point is the `bat` command, for example `bat README.md`, `bat src/*.rs`, or piped input such as `command | bat`. On some older Debian and Ubuntu releases, the executable is named `batcat` because of a package-name conflict. Installation is available through package managers on major Linux distributions, macOS, Windows, FreeBSD, OpenBSD, and Nix, as well as through Homebrew, MacPorts, WinGet, Chocolatey, Scoop, prebuilt GitHub Release binaries, or Rust’s `cargo`. Building from source requires Rust 1.79.0 or newer according to the supplied README; the documented Cargo entry points are `cargo install --path . --locked` for a local checkout and `cargo install --locked bat` from crates.io. Cargo installation does not automatically install all ancillary files, such as man pages and shell completions.

Typical uses include interactively reading source code with highlighting, reviewing Git-related changes, displaying logs, previewing search results, colorizing manual pages or help output, monitoring a file through `tail -f`, and acting as a mostly compatible `cat` replacement in shell workflows. Users who alias `cat` to `bat` may need `--paging=never` to retain conventional non-paging behavior.
